How to edit a markdown file without learning markdown

Updated: 2026-10-29

Most markdown editors show you the raw text: ## before headings, ** around bold words, | between table cells. That's fine for developers. But if you just want to fix a typo in a README, update a shared note, or add a line to an AI-written document, it gets in the way.

There's an easier way: edit the formatted page directly, the way you'd edit a document in a word processor.

Edit on the formatted page

In MD Reader:

  1. Open the .md file.
  2. Tap Edit.
  3. Tap anywhere in the text and type. Headings stay headings, lists stay lists, tables stay tables.
  4. Tap Save. The changes are written back to the original file.

Adding formatting without symbols

Type / on an empty line to open the insert menu:

  • Heading 1, 2, 3
  • Bulleted list, Numbered list, Checklist
  • Quote, Divider
  • Code block, Table, Math formula

When you do want the source

Sometimes you need the raw markdown, for example to fix a broken table or a diagram. Choose Edit markdown source to switch to the plain text, and Edit as formatted text to switch back.

Is my file changed in strange ways?

The editor writes standard markdown that other apps can read. The file stays a plain .md file, so it opens in Obsidian, VS Code, GitHub or any other markdown tool.

Safety nets

  • Unsaved drafts are kept if the app closes, and you're offered to restore them.
  • Version history: use Restore previous version if you change your mind after saving.
  • Read-only files (for example, some email attachments) can't be overwritten. Your changes stay in the app, and you can use Save as… to keep a copy.

Just ticking boxes?

You don't even need edit mode for checklists. Tap a checkbox while reading and it's saved. See markdown checklists on Android.
