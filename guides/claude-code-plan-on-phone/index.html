How to read a Claude Code plan on your phone

Updated: 2026-11-27

To read a Claude Code plan on your phone, copy the plan file from your computer to the phone and open it in a markdown reader. Claude Code keeps the plans it writes in plan mode in a folder on your computer, so the only real work is finding that folder and moving one file.

What a plan is and where Claude Code saves it

Claude Code is an AI coding assistant that runs in a terminal (the text window where you type commands). In plan mode it looks around your project and writes a plan, but doesn't change your files yet. You turn plan mode on by pressing Shift+Tab, or by starting a single message with /plan. Then you read the plan and choose whether Claude should go ahead or keep planning.

According to Claude Code's settings documentation, plan files are stored in ~/.claude/plans by default. The ~ stands for your home folder, so on Windows that's C:\Users\<your name>\.claude\plans. On a Mac it's inside your user folder. The .claude folder starts with a dot, which means it may be hidden: on a Mac press Cmd+Shift+. in Finder to show it, and on Windows you can paste the path straight into the File Explorer address bar.

While a plan is waiting for your approval, you can also press Ctrl+G to open it in your computer's default text editor.

Keeping plans inside your project

If you'd rather find plans next to your code, Claude Code has a setting called plansDirectory. It takes a folder path relative to your project, for example "plansDirectory": "./plans" in your project's .claude/settings.json file. New plans are then written to a plans folder in the project.

This helps if your project folder is already synced to Google Drive or another cloud service, because the plans travel with it. If the path points outside the project, Claude Code ignores it and uses the default folder.

Opening the plan on your phone

  1. Send the plan file to yourself. Uploading it to Google Drive, emailing it as an attachment or copying it over a USB cable all work.
  2. On your phone, tap the file and choose MD Reader, or open the app and use Open file.

MD Reader opens files ending in .md or .markdown and shows them formatted: headings become real headings, numbered steps line up, and file names or commands appear in code blocks with syntax highlighting and a Copy button. Wide tables scroll sideways instead of squeezing, and Mermaid diagrams are drawn as pictures. All of this works offline, and the app has no internet permission, so the plan never leaves your phone.

One thing to know: MD Reader doesn't connect to Claude Code and doesn't sync with your computer. You're reading a copy. If you ask Claude to revise the plan, send the new file over again. The steps for Drive are in how to open .md files from Google Drive.

Reading a long plan comfortably

Plans for bigger changes can run to several screens. A few things make them easier to follow:

  • Contents lists the plan's headings and highlights the section you're in, so you can jump straight to "Files to change" or "Testing".
  • Find in document searches for a file name or word inside the plan.
  • The plan reopens where you left off, so you can read half on the bus and finish later.
  • In the Aa settings you can pick a dark or sepia theme, a larger text size and a narrower page width.

If Claude made other files along the way, such as notes or a README, the guide to the .md files coding agents create explains which ones are worth reading. To open a whole folder of them at once and search across every document, you need the folder workspace in MD Reader Pro, a one-time purchase on Google Play. Reading single files is free.

Taking notes and sending changes back

If the plan includes a task list, you can tick the checkboxes while reading and they're saved to the file immediately. To add a comment or change a step, tap Edit and type on the formatted page, without remembering any markdown symbols (more on editing).

Remember that this only changes the copy on your phone. Claude Code won't see your notes until you send the file back to your computer and put it where Claude can read it, or simply paste your comments into the terminal next time you're at your desk. Many people find that the second option is enough: read on the phone, decide, then type "go ahead, but skip step 4" when they sit back down.
