Dark mode and text size for reading markdown on Android

Updated: 2026-10-29

Long markdown documents, like specs, study notes or a 3,000-word AI answer, are tiring to read with small text, bright white backgrounds or lines that run across the whole screen. A few settings make a big difference.

Themes

MD Reader has five themes:

Theme Good for
Auto Follows your phone's light/dark setting
Light Daytime, printing
Sepia Long reading sessions, warmer and softer than white
Dark Evenings and low light
Black OLED screens: true black saves battery and is easiest at night

Code blocks, math and diagrams switch colors with the theme, so they stay readable.

Get it on Google Play

Text size

Open Reading settings → Text size and adjust until you can read without holding the phone close. The setting applies to every document.

Page width

Page width sets how long each line can be:

  • Narrow / Normal: comfortable line length for prose
  • Wide / Full: more room for tables, code and diagrams

See reading markdown tables on a phone.

Font

Choose Sans for a clean screen look or Serif for a more book-like feel on long texts.

Find your way in long documents

  • Table of contents. Jump to any heading. The current section is highlighted.
  • Reading progress bar. See how far you are.
  • Find in document. Search for a word.
  • Resume reading. Every document reopens where you left off.

Language

The app interface is available in 27 languages. It follows your phone's language by default, and you can change it in Reading settings → Language.
