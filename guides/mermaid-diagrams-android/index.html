How to view Mermaid diagrams on Android

Updated: 2026-10-29

Mermaid is a way to describe diagrams with text. In a markdown file it looks like a code block:

```mermaid
flowchart LR
  A[Idea] --> B{Worth it?}
  B -->|yes| C[Build]
  B -->|no| D[Drop]
```

A viewer with Mermaid support turns this into a real flowchart. Without it, you only see the code.

Where Mermaid shows up

  • README files and documentation on GitHub and GitLab, which render Mermaid on their websites
  • AI answers. Claude and ChatGPT often draw architecture, process or timeline diagrams in Mermaid
  • Notes apps like Obsidian

See Mermaid diagrams on your phone

MD Reader draws Mermaid diagrams inside the app, without an internet connection.

  1. Open the .md file, or paste text with Paste from clipboard.
  2. Every mermaid code block is drawn as a diagram.
  3. Tap Show code above a diagram to see its source, and Show diagram to switch back.

Supported diagram types

Mermaid supports many diagram types, including:

  • Flowcharts (flowchart, graph)
  • Sequence diagrams (sequenceDiagram)
  • Class and state diagrams
  • Gantt charts and timelines
  • Pie charts
  • Mind maps

"This diagram can't be drawn"

If a diagram has a syntax error, MD Reader shows a short message instead of a blank space. Then:

  • Tap Show code to see the source.
  • Check for a missing arrow, bracket or quote. A label with special characters usually needs quotes: A["Step (1)"].
  • If the diagram came from an AI chat that was still writing, copy the full answer again.

Big diagrams on small screens

Wide diagrams keep their full size and scroll sideways, so labels stay readable. For complex ones, turn the phone sideways or use a tablet. See reading markdown on tablets and foldables.
