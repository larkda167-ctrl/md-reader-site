What is an AGENTS.md file? What it does and what goes in it

Updated: 2026-11-23

An AGENTS.md file is a plain text file of instructions for AI coding agents, the tools that write and change code for you, such as Codex. The agent reads it before it starts working, so it already knows how to build the project, how to test it and which rules to follow.

It's written in markdown, a simple way of formatting text with symbols like # and **. The file doesn't run anything by itself, so opening it to read it is safe. Editing it is different: the agent will act on what you change.

What goes in it

The AGENTS.md site describes the file as a README for agents. A README.md is written for people: what the project is and how to get started. AGENTS.md holds the extra detail an agent needs, which would only clutter the README.

There are no required fields. It's ordinary markdown and you can use any headings you like. The site suggests covering things such as:

  • Project overview: what the project is, in a few lines
  • Build and test commands: so the agent can check its own work
  • Code style: the conventions your project follows
  • Testing instructions: what must pass before the work counts as done
  • Security considerations: anything the agent must handle carefully

Commit and pull request rules or deployment steps can go in too. A small one looks like this:

# AGENTS.md

## Commands
- Install: npm install
- Test: npm test (run this before you finish)

## Code style
- Keep user-facing text in src/i18n

## Don't touch
- Files in /generated are created by a script

Where it goes

Put the file in the top folder of the project. That's enough for most projects.

A large project made of several separate parts can have one AGENTS.md inside each part. According to the AGENTS.md site, agents read the nearest file in the folder tree, so the closest one wins:

File Used for
AGENTS.md in the top folder Instructions for the whole project
AGENTS.md in a subfolder Instructions for work inside that folder. It takes precedence there

What you type to the agent in the chat comes before both. An explicit request from you overrides the file.

Which tools read it

AGENTS.md isn't tied to one product. It's an open format, now looked after by the Agentic AI Foundation under the Linux Foundation, and it grew out of work by several teams including OpenAI's Codex, Google's Jules, Cursor, Amp and Factory.

The AGENTS.md site lists more than twenty tools that use it, among them Codex, Cursor, Gemini CLI, GitHub Copilot's coding agent, Aider, Zed, Windsurf and VS Code. That's the point of the format: you write your project's rules once instead of keeping a separate file for every tool. Each tool has its own details, so check its documentation if a file doesn't seem to be picked up.

AGENTS.md and CLAUDE.md

CLAUDE.md does the same job for Claude Code, Anthropic's coding agent. If you see both in a project, they are two sets of standing instructions for different tools, and it's worth checking that they don't contradict each other. Our guide to what a CLAUDE.md file is covers that one, and the .md files coding agents create explains the others you may find next to it.

What to keep in mind

Don't put passwords or API keys in the file. It usually lives in the project alongside the code, so anyone who can see the project can read it.

Keep it current. The agent trusts what's written there, so an outdated test command or a rule you no longer follow sends it in the wrong direction. When you notice yourself correcting the same mistake twice, add a line.

Reading it on your phone

Opened in a plain text app, the file shows raw # and ** symbols. To read it formatted on Android:

  1. Send it to your phone. Coding agents usually run on a computer, so use Google Drive, an email attachment or a USB cable.
  2. Tap the file and choose MD Reader, or use Open file in the app.
