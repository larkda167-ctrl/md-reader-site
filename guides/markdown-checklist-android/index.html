How to use markdown checklists on Android

Updated: 2026-10-29

Markdown has a simple way to write to-do lists:

- [x] Book flights
- [ ] Renew passport
- [ ] Pack charger

[ ] is an open task and [x] is a done one. These task lists are used in READMEs, project notes, packing lists, study plans, and plans that AI assistants write for you.

The problem on a phone: most apps either show the brackets as text, or show checkboxes you can't tap.

Tick boxes that save to the file

In MD Reader, checklists are interactive while you read:

  1. Open the .md file.
  2. Tap a checkbox.
  3. That's it. The change is saved to the file right away. [ ] becomes [x] in the source.

You don't need to enter edit mode, and you never see the brackets.

Add new tasks

  1. Tap Edit.
  2. Put the cursor at the end of a task and press Enter to add another one.
  3. To start a new checklist, type / on an empty line and choose Checklist.
  4. Tap Save.

See editing markdown without learning markdown for more.

Ideas that work well

  • Shopping and packing lists you keep as .md files in a synced folder
  • Project to-dos in a README
  • Study plans and reading lists
  • Plans from an AI assistant. Ask ChatGPT or Claude for a step-by-step plan as a markdown checklist, paste it into MD Reader, and save it as a file. See saving AI answers as markdown.

Checklists in synced folders

If your notes live in Google Drive or another cloud app, open the file through that app's Open with option. Whether changes sync back depends on the cloud app. See opening .md files from Google Drive.

Why use markdown instead of a to-do app?

A .md checklist is just text. It works in any editor, on any computer, and in version control like Git. It won't disappear when an app shuts down, and you can mix tasks with notes, links and tables in one document.
