Markdown cheat sheet: the basic syntax with examples

Updated: 2026-11-28

Markdown uses a handful of ordinary characters to format text: # for headings, ** for bold, - for lists and | for tables. This cheat sheet shows each one with an example you can copy, following GitHub Flavored Markdown (GFM), the widely used version that GitHub documents.

If you've never met markdown before, what a .md file is explains where it comes from. Everything below is plain text, so you can type it in any notes app.

Headings and paragraphs

Start a line with one to six # signs, then a space. One # is the biggest heading, six is the smallest.

# Trip plan
## Day one
### Morning

A blank line between two blocks of text starts a new paragraph. Pressing Enter once usually doesn't: in a .md file the two lines are joined. To force a line break, end the line with two spaces or a backslash (\).

Bold, italic and strikethrough

**bold**  *italic*  ***bold and italic***  ~~crossed out~~

Underscores also work for emphasis: __bold__ and _italic_. Pick one style and stick to it, so the file stays easy to read as plain text.

Lists and checklists

Use -, * or + for a bulleted list, and numbers with a full stop for a numbered list. To put a list inside another, indent the inner item so it lines up with the text above it.

- Bread
- Fruit
  - Apples
  - Pears

1. Book the train
2. Pack

A checklist (also called a task list) is a bulleted list with a box in square brackets. Leave a space inside for "not done" and put an x in it for "done".

- [ ] Call the bank
- [x] Pay rent

Links and images

A link is the text in square brackets followed by the address in round brackets. An image is the same with a ! in front, and the bracket text describes the picture for people who can't see it.

[Read the guide](https://example.com/guide)
![A map of the route](route.png)

Code

Wrap a short piece of code or a file name in single backticks: `notes.md`. For a longer block, put three backticks on the line before and the line after. Adding a language name after the first three backticks lets apps color the code (this is called syntax highlighting).

```python
print("hello")
```

Tables

Separate columns with |. The second line, made of hyphens, divides the header row from the rest, and colons in it set the alignment: :--- left, :---: centered, ---: right. Leave a blank line before the table.

| Item   | Price |
| :---   | ---:  |
| Coffee | 3.50  |
| Cake   | 4.00  |

The columns don't have to line up in the source. If a cell needs a real | character, write it as \|.

Quotes, callouts and footnotes

Start a line with > to quote it. A callout is a highlighted box made from a quote whose first line names its type. GitHub supports five types: NOTE, TIP, IMPORTANT, WARNING and CAUTION.

> [!WARNING]
> Back up the file before you edit it.

A footnote has two parts: a marker in the text and the note itself, which can go anywhere in the file. It's shown at the bottom.

The museum opens at nine.[^1]

[^1]: Closed on Mondays.
