Cómo ver diagramas de Mermaid en Android

Actualizado: 2026-11-05

Mermaid es una forma de describir diagramas con texto. En un archivo markdown, tiene el aspecto de un bloque de código:

```mermaid
flowchart LR
  A[Idea] --> B{¿Vale la pena?}
  B -->|sí| C[Crear]
  B -->|no| D[Descartar]
```

Un visor compatible con Mermaid convierte esto en un diagrama de flujo real. Sin él, solo ves el código.

Dónde aparecen los diagramas de Mermaid

  • Archivos README y documentación en GitHub y GitLab, que los renderizan en sus sitios web.
  • Respuestas de IA. Claude y ChatGPT suelen dibujar diagramas de arquitectura, procesos o cronologías en Mermaid.
  • Aplicaciones de notas como Obsidian.

Ver diagramas de Mermaid en tu teléfono

MD Reader dibuja los diagramas de Mermaid dentro de la aplicación, sin necesidad de conexión a internet.

  1. Abre el archivo .md o pega texto con Pegar del portapapeles.
  2. Cada bloque de código mermaid se dibuja como un diagrama.
  3. Toca Ver código encima de un diagrama para ver su código fuente, y Ver diagrama para volver a cambiar.

Disponible en Google Play

Tipos de diagramas compatibles

Mermaid admite muchos tipos de diagramas, entre ellos:

  • Diagramas de flujo (flowchart, graph)
  • Diagramas de secuencia (sequenceDiagram)
  • Diagramas de clases y estados
  • Diagramas de Gantt y cronologías
  • Gráficos circulares
  • Mapas mentales

«Este diagrama no se puede dibujar»

Si un diagrama tiene un error de sintaxis, MD Reader muestra un breve mensaje en lugar de un espacio en blanco. En ese caso:

  • Toca Ver código para ver el origen.
  • Comprueba si falta alguna flecha, corchete o comilla. Una etiqueta con caracteres especiales suele necesitar comillas: A["Paso (1)"].
  • Si el diagrama proviene de un chat de IA que aún estaba escribiendo, copia la respuesta completa de nuevo.

Diagramas grandes en pantallas pequeñas

Los diagramas anchos conservan su tamaño completo y se desplazan hacia los lados, para que las etiquetas sigan siendo legibles. Para los más complejos, gira el teléfono o usa una tableta. Consulta cómo leer markdown en tabletas y plegables.
