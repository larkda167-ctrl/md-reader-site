Cómo editar un archivo Markdown sin saber Markdown

Actualizado: 2026-11-11

La mayoría de editores de Markdown muestran el texto sin formato: ## antes de los encabezados, ** alrededor de palabras en negrita o | entre celdas de una tabla. Eso está bien para programadores, pero si solo quieres corregir una errata en un README, actualizar una nota compartida o añadir una línea a un documento generado por IA, resulta incómodo.

Hay una forma más sencilla: editar directamente la página con formato, igual que harías en cualquier procesador de textos.

Edita directamente en la página con formato

En MD Reader:

  1. Abre el archivo .md.
  2. Toca Editar.
  3. Toca cualquier parte del texto y escribe. Los encabezados siguen siendo encabezados, las listas se mantienen como listas y las tablas como tablas.
  4. Toca Guardar. Los cambios se guardarán directamente en el archivo original.

Disponible en Google Play

Añadir formato sin usar símbolos

Escribe / en una línea vacía para abrir el menú de inserción:

  • Encabezado 1, 2, 3
  • Lista con viñetas, Lista numerada, Lista de tareas
  • Cita, Separador
  • Bloque de código, Tabla, Fórmula matemática

Si prefieres ver el código fuente

A veces hace falta ver el Markdown sin formato, por ejemplo para arreglar una tabla rota o un diagrama. Elige Editar el código Markdown para pasar al texto plano y Editar como texto con formato para volver.

¿Se alterará el archivo de forma extraña?

El editor genera Markdown estándar compatible con otras aplicaciones. El archivo sigue siendo un .md normal, por lo que podrás abrirlo sin problemas en Obsidian, VS Code, GitHub o cualquier otra herramienta de Markdown.

Medidas de seguridad

  • Borradores no guardados: se conservan si se cierra la aplicación y podrás restaurarlos al volver a abrirla.
  • Historial de versiones: usa la opción para restaurar una versión anterior si cambias de idea tras guardar.
  • Archivos de solo lectura: no se pueden sobrescribir (como algunos archivos adjuntos de correos). Tus cambios se conservan en la aplicación y puedes usar Guardar como… para guardar una copia.

¿Solo quieres marcar casillas?

Ni siquiera necesitas entrar en el modo de edición para las listas de tareas. Toca una casilla mientras lees y se guardará al instante. Consulta cómo usar listas de tareas en Markdown para Android.
