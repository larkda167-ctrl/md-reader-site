Qué es un archivo .md y cómo abrirlo en tu móvil Android

Actualizado: 2026-11-03

Un archivo que termina en .md es un documento de Markdown. Markdown es una forma de escribir texto con formato utilizando caracteres normales, por lo que el archivo es simplemente texto plano que cualquier dispositivo puede almacenar.

Aquí tienes un pequeño ejemplo. Esto es lo que contiene el archivo:

# Lista de compras

Comprar esto **hoy**:

- Leche
- Pan
- [ ] Llamar a la panadería

Un visor de Markdown lo convierte en una página con formato: un encabezado grande de "Lista de compras", la palabra "hoy" en negrita, una lista con viñetas y una casilla que puedes marcar.

Por qué hay tantos archivos .md hoy en día

  • Archivos README. Casi todos los proyectos de software tienen un README.md que explica de qué se trata.
  • Aplicaciones de notas. Obsidian, Logseq, Joplin y muchas otras aplicaciones guardan notas como archivos .md.
  • Asistentes de IA. ChatGPT, Claude y Gemini escriben sus respuestas en Markdown. Cuando guardas o exportas una respuesta, a menudo obtienes un archivo .md.
  • Agentes de programación de IA. Claude Code y Codex dejan archivos .md en tu proyecto, como CLAUDE.md, AGENTS.md y planes. Qué son esos archivos.
  • Documentación. Muchos manuales, wikis y apuntes de cursos están escritos en Markdown.

Markdown es popular porque se puede leer incluso sin un visor, funciona en cualquier sistema y es fácil de convertir a una página web o PDF.

Qué puede contener Markdown

  • Encabezados (#, ##)
  • Texto en negrita y cursiva
  • Listas con viñetas, numeradas y de tareas
  • Enlaces e imágenes
  • Tablas
  • Bloques de código
  • A menudo fórmulas matemáticas ($E = mc^2$) y diagramas (Mermaid)

Los dos últimos no forman parte del Markdown básico, por lo que los visores sencillos los muestran como texto plano. Un buen visor los renderiza.

Cómo leer un archivo .md en Android

Android no puede dar formato a Markdown por sí solo. Instala un visor de Markdown y abre el archivo con él.

¿Puedo simplemente cambiarle el nombre a .txt?

Puedes hacerlo y podrás leer el texto. Pero verás todos los símbolos, las tablas parecerán filas de caracteres | y las casillas no funcionarán. Por qué tu archivo .md muestra símbolos # y ** explica la diferencia.
