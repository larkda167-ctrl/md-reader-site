Solución: «Ninguna aplicación puede abrir este archivo» (.md)

Actualizado: 2026-11-08

Tocas un archivo .md y Android muestra «Ninguna aplicación puede abrir este archivo» (o «No se puede abrir el archivo»). El archivo está en perfecto estado: tu móvil simplemente no tiene ninguna app asociada a los archivos Markdown.

Por qué ocurre

Android elige la aplicación según el tipo de archivo. Los archivos Markdown suelen identificarse como text/markdown o como un tipo genérico. Casi ninguna app preinstalada los reconoce, por lo que el sistema no sabe con qué abrirlos.

Solución: instala un lector de Markdown

  1. Instala MD Reader desde Google Play. La app se registra para abrir archivos .md y .markdown.
  2. Vuelve a tocar el archivo.
  3. Selecciona MD Reader (y elige Siempre, si quieres).

Disponible en Google Play

¿Sigue sin abrirse?

El tipo de archivo no se reconoce bien. Algunas apps envían el archivo Markdown como un tipo desconocido, por lo que no aparece ningún lector en la lista. Abre MD Reader, toca Abrir archivo y elígelo desde el selector de archivos. Esto siempre funciona.

El archivo está dentro de un ZIP. Extráelo primero. En Files de Google, toca el archivo ZIP y selecciona Extraer.

Es un archivo adjunto o está en la nube. Descárgalo o usa la opción Abrir con de la app correspondiente. Consulta cómo abrir archivos adjuntos de correo y desde Google Drive.

Ahora se abre con la app equivocada. Ve a Ajustes → Aplicaciones, busca la aplicación que lo abre y entra en Abrir de forma predeterminada → Borrar valores predeterminados. Vuelve a tocar el archivo para elegir la app adecuada.

¿Y si en realidad no es Markdown?

Algunos programas antiguos usan la extensión .md para otros formatos, como imágenes de disco o datos de videojuegos. Si MD Reader muestra caracteres extraños en lugar de texto legible, es muy probable que no sea un archivo Markdown. Un documento Markdown de verdad siempre contiene texto legible.
