Hoja de trucos de Markdown: sintaxis básica y ejemplos

Actualizado: 2026-11-27

Markdown usa unos pocos caracteres comunes para dar formato al texto: # para los encabezados, ** para la negrita, - para las listas y | para las tablas. Esta hoja de trucos muestra cada uno con un ejemplo que puedes copiar, siguiendo GitHub Flavored Markdown (GFM), la versión ampliamente utilizada que documenta GitHub.

Si nunca antes has usado Markdown, qué es un archivo .md explica de dónde viene. Todo lo que aparece a continuación es texto sin formato, por lo que puedes escribirlo en cualquier aplicación de notas.

Encabezados y párrafos

Comienza una línea con de uno a seis signos # y luego un espacio. Un # es el encabezado más grande y seis es el más pequeño.

# Plan de viaje
## Día uno
### Mañana

Una línea en blanco entre dos bloques de texto inicia un nuevo párrafo. Presionar Intro una vez normalmente no lo hace: en un archivo .md las dos líneas se unen. Para forzar un salto de línea, termina la línea con dos espacios o una barra invertida (\).

Negrita, cursiva y tachado

**negrita**  *cursiva*  ***negrita y cursiva***  ~~tachado~~

Los guiones bajos también sirven para dar énfasis: __negrita__ y _italic_. Elige un estilo y mantén lo mismo para que el archivo sea fácil de leer como texto plano.

Listas y listas de tareas

Usa -, * o + para una lista con viñetas, y números con un punto para una lista numerada. Para poner una lista dentro de otra, indenta el elemento interno para que se alinee con el texto superior.

- Pan
- Fruta
  - Manzanas
  - Peras

1. Reservar el tren
2. Hacer la maleta

Una lista de tareas (también llamada checklist) es una lista con viñetas que incluye una casilla entre corchetes. Deja un espacio dentro si no está hecha y pon una x si está lista.

- [ ] Llamar al banco
- [x] Pagar el alquiler

Enlaces e imágenes

Un enlace es el texto entre corchetes seguido de la dirección entre paréntesis. Una imagen es lo mismo pero con un ! delante, y el texto entre corchetes describe la imagen para personas que no pueden verla.

Código

Envuelve una línea corta de código o el nombre de un archivo entre comillas invertidas simples: `notes.md`. Para un bloque más largo, coloca tres comillas invertidas en la línea anterior y en la posterior. Añadir el nombre del lenguaje tras las tres primeras comillas permite a las apps colorear el código (resaltado de sintaxis).

```python
print("hola")
```

Tablas

Separa las columnas con |. La segunda línea, hecha de guiones, separa la cabecera del resto, y los dos puntos definen la alineación: :--- izquierda, :---: centrado, ---: derecha. Deja una línea en blanco antes de la tabla.

| Artículo | Precio |
| :---     | ---:   |
| Café     | 3.50   |
| Pastel   | 4.00   |

Las columnas no tienen que alinearse en el código fuente. Si una celda necesita un carácter | real, escríbelo como \|.

Citas, notas de aviso y notas al pie

Empieza una línea con > para citarla. Un cuadro de aviso o callout es una caja resaltada a partir de una cita cuya primera línea indica su tipo. GitHub admite cinco tipos: NOTE, TIP, IMPORTANT, WARNING y CAUTION.

> [!WARNING]
> Haz una copia de seguridad del archivo antes de editarlo.

Una nota al pie tiene dos partes: un marcador en el texto y la nota en sí, que puede ir en cualquier parte del archivo. Se muestra al final.

El museo abre a las nueve.[^1]

[^1]: Cerrado los lunes.
