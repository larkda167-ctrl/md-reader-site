Cómo leer y copiar código de archivos Markdown en Android

Actualizado: 2026-11-09

El código en Markdown se escribe entre tres comillas invertidas:

```python
def greet(name):
    return f"¡Hola, {name}!"
```

En el móvil, el código es donde las aplicaciones de texto sin formato fallan más. Las líneas largas se parten por la mitad, la sangría se pierde (lo que estropea Python y YAML), no hay resaltado de sintaxis y seleccionar exactamente el fragmento que quieres copiar resulta muy incómodo.

Qué necesitas de un visor de código en el móvil

  • Sin cortes de línea automáticos. Las líneas largas se desplazan hacia los lados para que la sangría permanezca intacta.
  • Resaltado de sintaxis para el lenguaje indicado en el bloque (python, js, bash…).
  • Un botón para copiar que copie exactamente el bloque de código, sin espacios sobrantes ni las comillas invertidas.
  • Tipografía monoespaciada para que las columnas queden bien alineadas.

Bloques de código en MD Reader

MD Reader muestra cada bloque de código con resaltado de sintaxis, desplazamiento horizontal y un botón Copiar en la cabecera.

  1. Abre un archivo .md, un README o pega una respuesta de IA con Pegar del portapapeles.
  2. Desliza hacia los lados en las líneas largas.
  3. Toca Copiar en el bloque correspondiente. Verás la confirmación Copiado ✓.

Disponible en Google Play

Usos habituales

  • Comandos de instalación de un README. Cópialos en una aplicación de terminal como Termux o pásalos a tu ordenador. Consulta cómo leer README.md en Android.
  • Código generado por IA. ChatGPT y Claude encierran el código en bloques delimitados. Pega la respuesta en MD Reader para leerla cómodamente y copiar cada bloque por separado. Consulta cómo ver respuestas de ChatGPT con formato.
  • Fragmentos de configuración (YAML, JSON) donde la indentación es crítica.
  • Diffs. Un bloque diff resalta visualmente las líneas añadidas y eliminadas.

Consejos

  • Si el código se ve sin colores, revisa si falta indicar el lenguaje al inicio del bloque. ```python activa el resaltado; un simple ``` se muestra en texto plano.
  • Pon el móvil en horizontal o ajusta Ancho de página → Ancho si trabajas con líneas largas. Consulta los ajustes de lectura.
  • Los bloques mermaid se dibujan directamente como diagramas en lugar de código. Consulta cómo ver Mermaid en Android.
