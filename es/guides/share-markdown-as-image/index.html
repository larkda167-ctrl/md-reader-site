Cómo compartir documentos Markdown como imágenes en Android

Actualizado: 2026-11-24

Para compartir Markdown como una imagen, abre el documento en una aplicación que lo muestre con formato y exporta la página formateada como imágenes en lugar de enviar el texto plano. La persona que lo reciba verá encabezados, tablas y listas limpios, sin necesidad de ninguna aplicación especial.

Esto importa porque la mayoría de las aplicaciones de chat no entienden Markdown. Markdown es el formato de texto plano que usan los asistentes de IA y muchas aplicaciones de notas, donde # marca un encabezado y ** pone el texto en negrita. Si lo pegas en un chat grupal, tus amigos recibirán un muro de símbolos. Una imagen se ve igual en cualquier teléfono.

Por qué enviar Markdown como imágenes

Las imágenes solucionan varios problemas comunes a la vez:

  • El formato se conserva. Las tablas, las listas de tareas y los bloques de código se ven tal como los ves, no como caracteres | y -.
  • Nadie necesita instalar nada. Cualquier aplicación de mensajería puede mostrar una foto.
  • Se lee bien en un chat. La gente se desplaza por las imágenes más fácilmente que por un mensaje largo pegado o un archivo que tienen que abrir.

El inconveniente es que el texto de una imagen no puede ser copiado ni buscado por quien lo recibe. Si necesitan reutilizar las palabras, envía texto o un archivo en su lugar (más detalles a continuación).

Cómo compartir un documento como imágenes

En Android, MD Reader puede hacer esto en unos pocos toques:

  1. Abre el documento. Toca un archivo .md y elige MD Reader, o usa Abrir archivo en la aplicación. Para una respuesta que hayas copiado de ChatGPT, Claude o Gemini, usa Pegar como documento.
  2. Abre el menú (⋮) y toca Compartir, luego Compartir como imágenes.
  3. Verás el documento dividido en páginas, mostradas como miniaturas. Toca las páginas que quieras, o usa Seleccionar todo o Limpiar.
  4. Toca Compartir y elige la aplicación con la que deseas enviarlas, como WhatsApp. Las páginas seleccionadas se envían juntas como varias imágenes.

Cómo se dividen las páginas

MD Reader corta el documento en páginas del tamaño de una pantalla, por lo que cada imagen encaja cómodamente en un teléfono. Nunca corta a mitad de un párrafo, por lo que ninguna oración se divide entre dos fotos.

Por eso es útil seleccionar páginas. Si solo importan el resumen de la parte superior y una tabla, selecciona esas dos y deja el resto fuera. La otra persona recibe exactamente lo que necesita, no un desplazamiento largo.

Qué es gratis y qué requiere Pro

Compartir como imágenes es gratis, con dos límites: hasta 5 páginas a la vez y una pequeña marca "MD Reader" en cada imagen. MD Reader Pro, una compra única en Google Play, elimina ambos límites, por lo que puedes enviar cualquier cantidad de páginas sin la marca.

Si solo necesitas algunas páginas de vez en cuándo, la versión gratuita es suficiente. Para documentos más largos, también puedes enviarlos en lotes de cinco.

Cuándo el texto o el PDF es mejor

Las imágenes no siempre son la opción correcta:

  • Compartir como texto envía el propio código Markdown. Úsalo cuando la otra persona vaya a editar el contenido o pegarlo en otra aplicación que entienda Markdown.
  • Un PDF mantiene todo en un solo archivo que se puede imprimir o adjuntar a un correo electrónico. En MD Reader, Imprimir / Guardar como PDF es una función Pro. Consulta cómo convertir Markdown a PDF en Android.
  • El archivo en sí es mejor para cualquiera que vaya a seguir trabajando en él en una computadora.

Cosas a comprobar antes de enviar

  • Las imágenes de la web no aparecerán. MD Reader no tiene permiso de internet, por lo que las imágenes del documento que apuntan a direcciones web no se cargan y tampoco estarán en las imágenes compartidas. Las imágenes que solo enlazan a un sitio web se describen mejor con palabras.
  • Comprueba las miniaturas. Revisa las páginas seleccionadas una vez antes de tocar Compartir, para que no falte nada ni se incluya por error.
  • Datos personales. Una imagen es fácil de reenviar y difícil de retirar. Revisa las páginas en busca de nombres, números de teléfono o direcciones que no quisieras compartir.
