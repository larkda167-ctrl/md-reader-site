Cómo usar checklists de Markdown en Android

Actualizado: 2026-11-07

Markdown ofrece una forma muy sencilla de crear listas de tareas pendientes:

- [x] Reservar vuelos
- [ ] Renovar pasaporte
- [ ] Guardar cargador

[ ] representa una tarea pendiente y [x] una completada. Estas listas de tareas se usan habitualmente en archivos README, notas de proyectos, listas de equipaje, planes de estudio o respuestas generadas por asistentes de IA.

El problema en un móvil es que la mayoría de aplicaciones muestran los corchetes como texto simple o muestran casillas que no se pueden marcar.

Casillas interactivas que se guardan en el archivo

En MD Reader, las listas de tareas son interactivas mientras lees:

  1. Abre el archivo .md.
  2. Toca una casilla.
  3. Listo. El cambio se guarda al instante en el archivo: en el código fuente, [ ] pasa a ser [x].

Disponible en Google Play

No necesitas activar el modo de edición ni volver a ver los corchetes de texto.

Añadir nuevas tareas

  1. Toca Editar.
  2. Coloca el cursor al final de una tarea y pulsa Intro para añadir otra.
  3. Para crear una lista nueva, escribe / en una línea vacía y selecciona Lista de tareas.
  4. Toca Guardar.

Consulta cómo editar Markdown sin saber Markdown para más información.

Casos prácticos muy útiles

  • Listas de compras o de viaje organizadas como archivos .md en una carpeta sincronizada.
  • Tareas pendientes de un proyecto dentro de un archivo README.
  • Planes de estudio y listas de lecturas pendientes.
  • Planes generados por IA: Pídele a ChatGPT o Claude un plan paso a paso con formato de checklist en Markdown, pégalo en MD Reader y guárdalo como archivo. Consulta cómo guardar respuestas de IA en Markdown.

Listas de tareas en carpetas sincronizadas

Si guardas tus notas en Google Drive u otra app en la nube, abre el archivo mediante la opción Abrir con de esa aplicación. La sincronización automática dependerá de cómo gestione los cambios cada servicio en la nube. Consulta cómo abrir archivos .md desde Google Drive.

¿Por qué usar Markdown en lugar de una app de tareas?

Una lista en un archivo .md no es más que texto plano. Funciona en cualquier editor, en cualquier ordenador y en sistemas de control de versiones como Git. Tus listas no desaparecerán si un servicio cierra, y puedes combinar tareas con notas, enlaces y tablas dentro del mismo documento.
