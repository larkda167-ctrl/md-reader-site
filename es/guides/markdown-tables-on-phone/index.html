Cómo leer tablas de Markdown en el móvil con MD Reader

Actualizado: 2026-11-05

Las tablas de Markdown se escriben así:

| Plan  | Precio | Almacenamiento | Soporte |
|-------|-------:|----------------|---------|
| Gratis |    $0  | 5 GB           | Correo  |
| Pro   |    $8  | 100 GB         | Chat    |

En una aplicación de texto plano en el teléfono, esto se convierte en líneas envueltas de caracteres | que son casi imposibles de seguir. Incluso algunas aplicaciones de Markdown comprimen cada columna en la pantalla hasta que cada celda tiene una sola palabra de ancho.

Qué hace que una tabla sea legible en un teléfono

  • Desplazamiento horizontal. La tabla mantiene su ancho natural y te deslizas hacia los lados. El texto de cada celda se mantiene en una o dos líneas.
  • Alineación. ---: significa alineado a la derecha (ideal para números) y :---: significa centrado. Un visor adecuado respeta eso.
  • Celdas legibles. Las negritas, el código y los enlaces dentro de las celdas también deben tener formato.

Cómo leer tablas en MD Reader

MD Reader renderiza tablas al estilo de GitHub. Las tablas anchas se desplazan horizontalmente dentro de la página, por lo que el resto del documento no se mueve.

  1. Abre el archivo .md o pega el texto con Pegar del portapapeles.
  2. Desliza el dedo hacia la izquierda y hacia la derecha en la tabla para ver todas las columnas.
  3. Gira el teléfono horizontalmente para ver tablas muy anchas. Verás más columnas a la vez.

Consejos para tablas grandes

  • Usa el modo horizontal o una tablet. En tablets y dispositivos plegables, MD Reader utiliza un diseño más ancho. Consulta cómo leer en tablets y dispositivos plegables.
  • Cambia el ancho de página. En Ajustes de lectura, configura Ancho de página a Ancho o Completo para dar más espacio a las tablas. Consulta ajustes de lectura cómodos.
  • Reduce el tamaño del texto para un documento si necesitas comparar muchas columnas.

Tablas de respuestas de IA

ChatGPT, Claude y Gemini adoran las tablas para las comparaciones. Cuando copias una respuesta, la tabla llega como código fuente de Markdown. Pégala en MD Reader para verla como una tabla real. Consulta cómo leer respuestas de ChatGPT como Markdown con formato.

¿Por qué mi tabla se muestra como texto plano?

Causas comunes:

  • No hay una fila separadora de cabecera (|---|---|) debajo de la primera línea.
  • Falta una línea en blanco antes de la tabla.
  • Las filas tienen un número diferente de columnas con |.

Arréglalo en la fuente (Editar el código Markdown en MD Reader) y la tabla se renderizará.
