Cómo abrir un archivo .md en Android

Actualizado: 2026-11-03

Un archivo .md es un documento de markdown: texto plano con algunos símbolos (#, **, -) que indican encabezados, texto en negrita y listas. Android no incluye ninguna aplicación nativa para interpretar esos símbolos. Por eso, al tocar un archivo .md, normalmente obtienes uno de estos resultados:

  • "Ninguna aplicación puede abrir este archivo"
  • Un editor de texto que muestra los símbolos # y ** en bruto
  • Un navegador que vuelve a descargar el archivo en lugar de mostrarlo

Para leerlo como un documento formateado, necesitas un visor de markdown.

Paso 1: Instala un visor de markdown

Instala un visor de markdown desde Google Play. En esta guía usaremos MD Reader, que es gratuito, funciona sin conexión y no solicita acceso a internet.

Disponible en Google Play

Paso 2: Abre el archivo

Puedes abrir el archivo desde cualquier ubicación.

Desde la aplicación Archivos o Descargas

  1. Abre Archivos (o Mis archivos en Samsung) y busca el archivo .md.
  2. Tócalo. Si Android te pregunta qué aplicación usar, elige MD Reader.
  3. Toca Siempre si quieres que los archivos .md se abran con esta aplicación de forma predeterminada.

Desde dentro de la aplicación

  1. Abre MD Reader.
  2. Toca Abrir archivo.
  3. Selecciona el archivo en el selector de archivos de Android. Desde ahí puedes explorar Descargas, el almacenamiento interno y aplicaciones en la nube como Google Drive.

Desde otra aplicación

Si una aplicación permite compartir un archivo o texto, toca Compartir y elige MD Reader. Esto funciona con muchas aplicaciones de almacenamiento en nube, chat y notas.

Paso 3: Lee, busca y edita

Una vez abierto el archivo, verás los encabezados, las tablas, los bloques de código, los enlaces y las listas de tareas correctamente formateados. Podrás:

  • Abrir el índice para saltar entre secciones
  • Usar Buscar en el documento para buscar texto
  • Tocar Editar para corregir un error tipográfico directamente en la página con formato, sin tocar los símbolos de markdown

Si el archivo sigue sin abrirse

  • El nombre del archivo no termina en .md. Algunas aplicaciones guardan el markdown como .txt o .markdown. Ábrelo desde dentro de MD Reader con Abrir archivo.
  • Es un archivo adjunto de correo electrónico. Descárgalo primero y luego ábrelo. Consulta cómo abrir un archivo adjunto de correo .md.
  • Sigue apareciendo "Ninguna aplicación puede abrir este archivo". Consulta cómo solucionar que ninguna aplicación pueda abrir archivos .md.
