Qué es un archivo AGENTS.md: funciones y contenido

Actualizado: 2026-11-23

Un archivo AGENTS.md es un archivo de texto plano con instrucciones para los agentes de programación de inteligencia artificial, las herramientas que escriben y modifican código por ti, como Codex. El agente lo lee antes de empezar a trabajar, por lo que ya sabe cómo compilar el proyecto, cómo probarlo y qué reglas debe seguir.

Está escrito en Markdown, una forma sencilla de dar formato al texto con símbolos como # y **. El archivo no ejecuta nada por sí mismo, así que abrirlo para leerlo es seguro. Editarlo es diferente: el agente actuará según lo que cambies.

Qué contiene

El sitio web de AGENTS.md describe el archivo como un archivo README para agentes. Un README.md está escrito para personas: qué es el proyecto y cómo empezar. AGENTS.md contiene los detalles adicionales que necesita un agente y que de otro modo saturarían el README.

No hay campos obligatorios. Es Markdown normal y puedes usar los encabezados que quieras. El sitio sugiere incluir aspectos como:

  • Resumen del proyecto: qué es el proyecto en unas pocas líneas.
  • Comandos de compilación y prueba: para que el agente pueda verificar su propio trabajo.
  • Estilo de código: las convenciones que sigue tu proyecto.
  • Instrucciones de prueba: lo que debe pasar para considerar el trabajo terminado.
  • Consideraciones de seguridad: cualquier aspecto que el agente deba manejar con precaución.

También se pueden incluir reglas para confirmaciones (commits) y solicitudes de extracción (pull requests) o pasos de despliegue. Un ejemplo sencillo tiene este aspecto:

# AGENTS.md

## Comandos
- Instalar: npm install
- Probar: npm test (ejecuta esto antes de terminar)

## Estilo de código
- Mantén el texto visible para el usuario en src/i18n

## No tocar
- Los archivos en /generated son creados por un script

Dónde se coloca

Coloca el archivo en la carpeta principal del proyecto. Eso es suficiente para la mayoría de los proyectos.

Un proyecto grande formado por varias partes independientes puede tener un AGENTS.md dentro de cada sección. Según el sitio de AGENTS.md, los agentes leen el archivo más cercano en el árbol de carpetas, por lo que el más próximo tiene prioridad:

Archivo Utilizado para
AGENTS.md en la carpeta principal Instrucciones para todo el proyecto
AGENTS.md en una subcarpeta Instrucciones para el trabajo dentro de esa carpeta. Tiene preferencia allí

Lo que le escribes al agente en el chat va antes que ambos. Una solicitud explícita tuya anula el archivo.

Qué herramientas lo leen

AGENTS.md no está vinculado a un único producto. Es un formato abierto, gestionado actualmente por la Agentic AI Foundation bajo la Linux Foundation, y surgió a partir del trabajo de varios equipos, incluidos Codex de OpenAI, Jules de Google, Cursor, Amp y Factory.

El sitio de AGENTS.md enumera más de veinte herramientas que lo utilizan, entre ellas Codex, Cursor, Gemini CLI, el agente de programación de GitHub Copilot, Aider, Zed, Windsurf y VS Code. Ese es el objetivo del formato: escribes las reglas de tu proyecto una sola vez en lugar de mantener un archivo separado para cada herramienta. Cada herramienta tiene sus propias particularidades, así que consulta su documentación si parece que un archivo no se está detectando.

AGENTS.md y CLAUDE.md

CLAUDE.md cumple la misma función para Claude Code, el agente de programación de Anthropic. Si ves ambos en un proyecto, son dos conjuntos de instrucciones permanentes para diferentes herramientas, y conviene comprobar que no se contradigan entre sí. Nuestra guía sobre qué es un archivo CLAUDE.md cubre ese tema, y los archivos .md que crean los agentes de código explica los otros que puedes encontrar junto a él.

Qué debes tener en cuenta

No incluyas contraseñas ni claves de API en el archivo. Por lo general, este se encuentra en el proyecto junto al código, por lo que cualquier persona que tenga acceso al proyecto podrá leerlo.

Mantén el archivo actualizado. El agente confía en lo que está escrito allí, por lo que un comando de prueba obsoleto o una regla que ya no sigues lo desviará en la dirección incorrecta. Cuando notes que corriges el mismo error dos veces, añade una línea.

Cómo leerlo en el teléfono

Si se abre en una aplicación de texto plano, el archivo muestra los símbolos brutos # y **. Para leerlo con formato en Android:

  1. Envíalo a tu teléfono. Los agentes de código suelen ejecutarse en un ordenador, así que usa Google Drive, un archivo adjunto de correo electrónico o un cable USB.
  2. Toca el archivo y selecciona MD Reader, o usa Abrir archivo en la aplicación.

Disponible en Google Play

Los encabezados, las tablas y los bloques de código aparecen formateados, y Índice te permite saltar entre secciones. Las etiquetas como <example>, que son comunes en los archivos de instrucciones, se muestran tal como están escritas en lugar de desaparecer. En el caso de Drive, consulta cómo abrir archivos .md desde Google Drive.

MD Reader no se conecta a Codex ni a ninguna otra herramienta de programación y no se sincroniza con tu ordenador, por lo que lo que estás leyendo es una copia. Vuelve a enviarlo después de que cambie. Puedes tocar Editar y modificar la copia, pero el agente no verá esos cambios hasta que devuelvas el archivo a tu ordenador.
