Guia de Markdown: sintaxe básica com exemplos

Atualizado: 2026-11-27

O Markdown usa alguns caracteres comuns para formatar texto: # para títulos, ** para negrito, - para listas e | para tabelas. Este guia mostra cada um com um exemplo que você pode copiar, seguindo o GitHub Flavored Markdown (GFM), a versão amplamente utilizada documentada pelo GitHub.

Se você nunca viu markdown antes, o que é um arquivo .md explica de onde ele vem. Tudo abaixo é texto simples, então você pode digitá-lo em qualquer aplicativo de notas.

Títulos e parágrafos

Comece uma linha com um a seis sinais de #, seguidos de um espaço. Um # é o maior título, e seis é o menor.

# Plano de viagem
## Primeiro dia
### Manhã

Uma linha em branco entre dois blocos de texto inicia um novo parágrafo. Pressionar Enter uma vez geralmente não faz isso: em um arquivo .md as duas linhas ficam juntas. Para forçar uma quebra de linha, termine a linha com dois espaços ou uma barra invertida (\).

Negrito, itálico e riscado

**negrito**  *itálico*  ***negrito e itálico***  ~~riscado~~

Sublinhados também funcionam para ênfase: __negrito__ e _itálico_. Escolha um estilo e mantenha-o para que o arquivo continue fácil de ler como texto simples.

Listas e listas de tarefas

Use -, * ou + para uma lista com marcadores, e números com um ponto para uma lista numerada. Para colocar uma lista dentro de outra, recue o item interno para que ele se alinie com o texto acima dele.

- Pão
- Fruta
  - Maçãs
  - Pêras

1. Reservar o trem
2. Fazer as malas

Uma lista de tarefas (também chamada de checklist) é uma lista com marcadores contendo uma caixa entre colchetes. Deixe um espaço dentro para "não feito" e coloque um x para "feito".

- [ ] Ligar para o banco
- [x] Pagar o aluguel

Links e imagens

Um link é o texto entre colchetes seguido pelo endereço entre parênteses. Uma imagem é a mesma coisa com um ! na frente, e o texto entre colchetes descreve a imagem para pessoas que não podem vê-la.

Código

Envolva um pedaço curto de código ou nome de arquivo em crases simples: `notes.md`. Para um bloco mais longo, coloque três crases na linha anterior e na linha posterior. Adicionar um nome de linguagem após as três primeiras crases permite que os aplicativos coloram o código (isso é chamado de destaque de sintaxe).

```python
print("olá")
```

Tabelas

Separe colunas com |. A segunda linha, feita de hífens, divide o cabeçalho do restante, e dois-pontos definem o alinhamento: :--- à esquerda, :---: centralizado, ---: à direita. Deixe uma linha em branco antes da tabela.

| Item   | Preço |
| :---   | ---:  |
| Café   | 3,50  |
| Bolo   | 4,00  |

As colunas não precisam se alinharem no código fonte. Se uma célula precisar de um caractere | real, escreva-o como \|.

Citações, notas de destaque e notas de rodapé

Comece uma linha com > para citá-la. Uma nota de destaque é uma caixa destacada feita a partir de uma citação cuja primeira linha nomeia seu tipo. O GitHub suporta cinco tipos: NOTE, TIP, IMPORTANT, WARNING e CAUTION.

> [!WARNING]
> Faça backup do arquivo antes de editá-lo.

Uma nota de rodapé tem duas partes: um marcador no texto e a nota em si, que pode ir em qualquer lugar no arquivo. Ela é exibida na parte inferior.

O museu abre às nove.[^1]

[^1]: Fechado às segundas-feiras.

Verificando o que você escreveu no seu celular

A maneira mais rápida de aprender a sintaxe é vê-la formatada. Se você abrir um arquivo .md no Android e vir símbolos brutos de # e **, o aplicativo está exibindo o texto simples, e não a formatação (por que isso acontece).

Toque em Colar da área de transferência para testar qualquer exemplo desta página ou abra seu próprio arquivo.
