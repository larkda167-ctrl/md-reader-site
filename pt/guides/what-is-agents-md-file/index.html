O que é um arquivo AGENTS.md? O que ele faz e o que contém

Atualizado: 2026-11-23

Um arquivo AGENTS.md é um arquivo de texto simples contendo instruções para agentes de codificação de IA, que são as ferramentas que escrevem e alteram código para você, como o Codex. O agente o lê antes de começar a trabalhar, para já saber como compilar o projeto, testá-lo e quais regras seguir.

Ele é escrito em markdown, uma maneira simples de formatar texto usando símbolos como # e **. O arquivo não executa nada por si só, então abri-lo para leitura é seguro. Editá-lo é diferente: o agente agirá com base no que você alterar.

O que colocar nele

O site do AGENTS.md descreve o arquivo como um README para agentes. Um README.md é escrito para pessoas: explica o que é o projeto e como começar. O AGENTS.md contém os detalhes extras que um agente precisa, os quais apenas lotariam o README.

Não há campos obrigatórios. É um markdown comum e você pode usar os cabeçalhos que quiser. O site sugere cobrir tópicos como:

  • Visão geral do projeto: o que o projeto é, em poucas linhas
  • Comandos de compilação e teste: para que o agente possa verificar seu próprio trabalho
  • Estilo de código: as convenções que seu projeto segue
  • Instruções de teste: o que deve passar para que o trabalho seja considerado concluído
  • Considerações de segurança: qualquer coisa que o agente deva manipular com cuidado

Regras de commit e pull request ou etapas de implantação também podem ser incluídas. Um exemplo simples se parece com isto:

# AGENTS.md

## Comandos
- Instalação: npm install
- Teste: npm test (execute isto antes de terminar)

## Estilo de código
- Mantenha o texto voltado para o usuário em src/i18n

## Não mexa
- Os arquivos em /generated são criados por um script

Onde ele fica

Coloque o arquivo na pasta principal do projeto. Isso é suficiente para a maioria dos projetos.

Um projeto grande composto por várias partes separadas pode ter um AGENTS.md dentro de cada parte. De acordo com o site do AGENTS.md, os agentes leem o arquivo mais próximo na árvore de pastas, então o mais próximo vence:

Arquivo Usado para
AGENTS.md na pasta principal Instruções para todo o projeto
AGENTS.md em uma subpasta Instruções para o trabalho dentro dessa pasta. Tem precedência ali

O que você digita para o agente no chat vem antes de ambos. Uma solicitação explícita sua substitui o arquivo.

Quais ferramentas o leem

O AGENTS.md não está vinculado a um único produto. É um formato aberto, atualmente gerenciado pela Agentic AI Foundation sob a Linux Foundation, e surgiu do trabalho de várias equipes, incluindo o Codex da OpenAI, o Jules do Google, Cursor, Amp e Factory.

O site do AGENTS.md lista mais de vinte ferramentas que o utilizam, entre elas Codex, Cursor, Gemini CLI, o agente de codificação do GitHub Copilot, Aider, Zed, Windsurf e VS Code. Esse é o objetivo do formato: você escreve as regras do seu projeto uma vez em vez de manter um arquivo separado para cada ferramenta. Cada ferramenta tem suas próprias especificidades, portanto, verifique a documentação dela caso um arquivo pareça não estar sendo detectado.

AGENTS.md e CLAUDE.md

O CLAUDE.md faz o mesmo trabalho para o Claude Code, o agente de codificação da Anthropic. Se você vir ambos em um projeto, eles são dois conjuntos de instruções permanentes para ferramentas diferentes, e vale a pena verificar se eles não se contradizem. Nosso guia sobre o que é um arquivo CLAUDE.md aborda esse assunto, e os arquivos .md criados por agentes de codificação explica os outros que você pode encontrar ao lado dele.

O que ter em mente

Não coloque senhas ou chaves de API no arquivo. Ele geralmente fica no projeto junto com o código, então qualquer pessoa que possa ver o projeto pode lê-lo.

Mantenha-o atualizado. O agente confia no que está escrito ali, portanto, um comando de teste desatualizado ou uma regra que você não segue mais o enviará na direção errada. Quando perceber que está corrigindo o mesmo erro duas vezes, adicione uma linha.

Lendo no seu celular

Aberto em um aplicativo de texto simples, o arquivo mostra os símbolos brutos # e **. Para lê-lo formatado no Android:

  1. Envie-o para o seu celular. Agentes de codificação geralmente rodam em um computador, então use o Google Drive, um anexo de e-mail ou um cabo USB.
  2. Toque no arquivo e escolha MD Reader, ou use Abrir arquivo no aplicativo.

Disponível no Google Play

Cabeçalhos, tabelas e blocos de código aparecem formatados, e o Sumário permite pular entre as seções. Tags como <example>, que são comuns em arquivos de instrução, são mostradas como escritas em vez de desaparecerem. Para o Drive, consulte como abrir arquivos .md do Google Drive.

O MD Reader não se conecta ao Codex ou a qualquer outra ferramenta de codificação e não sincroniza com o seu computador, portanto, o que você está lendo é uma cópia. Envie-o novamente após alterações. Você pode tocar em Editar e alterar a cópia, mas o agente não verá isso até que você envie o arquivo de volta para o seu computador.
