Como ler tabelas Markdown no celular

Atualizado: 2026-11-05

As tabelas em Markdown são escritas assim:

| Plano  | Preço | Armazenamento | Suporte |
|--------|------:|---------------|---------|
| Grátis |    R$0| 5 GB          | E-mail  |
| Pro    |   R$40| 100 GB        | Chat    |

Em um aplicativo de texto simples no celular, isso se transforma em linhas quebradas de caracteres | que são quase impossíveis de entender. Até mesmo alguns aplicativos de markdown comprimem cada coluna na tela até que cada célula fique com uma palavra de largura.

O que torna uma tabela legível no celular

  • Rolagem horizontal. A tabela mantém sua largura natural e você desliza para os lados. O texto em cada célula fica em uma ou duas linhas.
  • Alinhamento. ---: significa alinhado à direita (bom para números) e :---: significa centralizado. Um visualizador adequado respeita isso.
  • Células legíveis. Negrito, código e links dentro das células também devem ser formatados.

Lendo tabelas no MD Reader

O MD Reader renderiza tabelas no estilo GitHub. Tabelas largas rolam para os lados dentro da página, para que o resto do documento não se mova.

  1. Abra o arquivo .md ou cole o texto com Colar da área de transferência.
  2. Deslize para a esquerda e para a direita na tabela para ver todas as colunas.
  3. Vire o celular de lado para tabelas muito largas. Você verá mais colunas de uma vez.

Dicas para tabelas grandes

  • Use a orientação paisagem ou um tablet. Em tablets e dobráveis, o MD Reader usa um layout mais largo. Veja leitura em tablets e dobráveis.
  • Altere a largura da página. Em Ajustes de leitura, defina Largura da página como Larga ou Total para dar mais espaço às tabelas. Veja ajustes confortáveis de leitura.
  • Diminua o texto para um documento se precisar comparar muitas colunas.

Tabelas de respostas de IA

ChatGPT, Claude e Gemini adoram tabelas para comparações. Quando você copia uma resposta, a tabela vem como código-fonte markdown. Cole-a no MD Reader para vê-la como uma tabela real. Veja lendo respostas do ChatGPT como markdown formatado.

Por que minha tabela aparece como texto simples?

Causas comuns:

  • Não há uma linha separadora de cabeçalho (|---|---|) abaixo da primeira linha.
  • Falta uma linha em branco antes da tabela.
  • As linhas têm números diferentes de colunas |.

Corrija isso no código-fonte (Editar o código Markdown no MD Reader) e a tabela será renderizada.
