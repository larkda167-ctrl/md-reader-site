Como editar arquivos markdown sem precisar aprender a sintaxe

Atualizado: 2026-11-03

A maioria dos editores de markdown mostra o texto bruto: ## antes dos títulos, ** ao redor de palavras em negrito, | entre as células de tabela. Isso funciona bem para desenvolvedores. Mas se você só quer corrigir um erro de digitação em um README, atualizar uma nota compartilhada ou adicionar uma linha a um documento gerado por IA, isso acaba atrapalhando.

Existe um jeito mais fácil: edite a página formatada diretamente, do mesmo jeito que você faria em um processador de texto.

Edite na página formatada

No MD Reader:

  1. Abra o arquivo .md.
  2. Toque em Editar.
  3. Toque em qualquer lugar no texto e comece a digitar. Títulos continuam sendo títulos, listas continuam sendo listas, tabelas continuam sendo tabelas.
  4. Toque em Salvar. As alterações são gravadas de volta no arquivo original.

Disponível no Google Play

Adicionando formatação sem símbolos

Digite / em uma linha vazia para abrir o menu de inserção:

  • Título 1, 2, 3
  • Lista com marcadores, Lista numerada, Lista de tarefas
  • Citação, Divisor
  • Bloco de código, Tabela, Fórmula matemática

Quando você precisar do código-fonte

Às vezes você precisa do markdown bruto, por exemplo, para consertar uma tabela quebrada ou um diagrama. Escolha Editar o código Markdown para alternar para o texto simples, e Editar como texto formatado para voltar.

Meu arquivo é alterado de formas estranhas?

O editor escreve um markdown padrão que outros aplicativos conseguem ler. O arquivo continua sendo um arquivo .md simples, então ele abre no Obsidian, VS Code, GitHub ou em qualquer outra ferramenta de markdown.

Redes de segurança

  • Rascunhos não salvos são mantidos caso o aplicativo feche, e você poderá restaurá-los.
  • Histórico de versões: use Restaurar versão anterior se mudar de ideia depois de salvar.
  • Arquivos somente leitura (por exemplo, alguns anexos de e-mail) não podem ser sobrescritos. Suas alterações ficam no aplicativo e você pode usar Salvar como… para guardar uma cópia.

Apenas marcando caixas?

Você nem precisa do modo de edição para listas de tarefas. Toque em uma caixa de seleção durante a leitura e ela será salva. Veja listas de tarefas em markdown no Android.
