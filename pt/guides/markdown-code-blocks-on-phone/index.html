Como ler e copiar códigos de arquivos markdown no celular

Atualizado: 2026-11-10

O código em markdown é escrito entre três crases:

```python
def greet(name):
    return f"Hello, {name}!"

```

Em um celular, o código é onde os aplicativos de texto simples falham mais. As linhas quebram no meio, a indentação se perde (o que quebra Python e YAML), não há destaque de sintaxe e selecionar exatamente o texto correto para copiar é trabalhoso.

O que você espera de um visualizador de código no celular

  • Sem quebra de linha automática. Linhas longas rolam lateralmente para que a indentação permaneça intacta.
  • Destaque de sintaxe para a linguagem informada no bloco de código (python, js, bash…).
  • Um botão de cópia que copia exatamente o bloco de código, sem espaços extras ou crases.
  • Fonte monoespaçada para que as colunas fiquem alinhadas.

Blocos de código no MD Reader

O MD Reader exibe todos os blocos de código delimitados com destaque de sintaxe, rolagem horizontal e um botão Copiar no cabeçalho.

  1. Abra um arquivo .md, um README ou cole uma resposta de IA com Colar da área de transferência.
  2. Arraste para o lado em linhas longas.
  3. Toque em Copiar em um bloco. Você verá Copiado ✓.

Disponível no Google Play

Usos comuns

  • Comandos de instalação de um README. Copie-os para um aplicativo de terminal como o Termux ou envie-os para o seu computador. Veja lendo README.md no Android.
  • Código de respostas de IA. O ChatGPT e o Claude colocam códigos em blocos delimitados. Cole a resposta no MD Reader para lê-la corretamente e copiar um bloco por vez. Veja lendo respostas do ChatGPT formatadas.
  • Trechos de configuração (YAML, JSON) onde a indentação importa.
  • Diffs. Um bloco diff destaca as linhas adicionadas e removidas.

Dicas

  • Se o código aparecer sem cores, o bloco de código pode estar sem o nome da linguagem. ```python destaca, mas um ``` simples não.
  • Vire o celular de lado ou defina Largura da página → Largo para linhas longas. Veja ajustes de leitura.
  • Blocos mermaid são renderizados como diagramas em vez de código. Veja Mermaid no Android.
