Como ler um plano do Claude Code no seu celular

Atualizado: 2026-11-26

Para ler um plano do Claude Code no seu celular, copie o arquivo de plano do computador para o aparelho e abra-o em um leitor de markdown. O Claude Code guarda os planos que cria no modo de planejamento em uma pasta no seu computador, então o único trabalho real é achar essa pasta e mover um arquivo.

O que é um plano e onde o Claude Code o salva

O Claude Code é um assistente de programação por IA que roda em um terminal (a janela de texto onde você digita comandos). No modo de planejamento, ele analisa o seu projeto e escreve um plano, mas ainda não altera seus arquivos. Você ativa o modo de planejamento pressionando Shift+Tab ou iniciando uma mensagem com /plan. Depois, você lê o plano e decide se o Claude deve prosseguir ou continuar planejando.

De acordo com a documentação de configurações do Claude Code, os arquivos de plano ficam salvos em ~/.claude/plans por padrão. O ~ representa sua pasta de usuário, então no Windows ela fica em C:\Users\<seu nome>\.claude\plans. No Mac, fica dentro da sua pasta de usuário. A pasta .claude começa com ponto, o que significa que pode estar oculta: no Mac, pressione Cmd+Shift+. no Finder para exibi-la, e no Windows você pode colar o caminho diretamente na barra de endereços do Explorador de Arquivos.

Enquanto um plano aguarda sua aprovação, você também pode pressionar Ctrl+G para abri-lo no editor de texto padrão do seu computador.

Mantendo os planos dentro do seu projeto

Se preferir localizar os planos junto ao seu código, o Claude Code tem uma configuração chamada plansDirectory. Ela aceita um caminho de pasta relativo ao seu projeto, por exemplo, "plansDirectory": "./plans" no arquivo .claude/settings.json do seu projeto. Os novos planos serão salvos em uma pasta plans no projeto.

Isso ajuda se a pasta do seu projeto já estiver sincronizada com o Google Drive ou outro serviço de nuvem, pois os planos viajam junto com ela. Se o caminho apontar para fora do projeto, o Claude Code o ignorará e usará a pasta padrão.

Abrindo o plano no seu celular

  1. Envie o arquivo de plano para você mesmo. Fazer o upload para o Google Drive, enviá-lo por e-mail como anexo ou copiá-lo via cabo USB funcionam.
  2. No seu celular, toque no arquivo e escolha Abrir arquivo, ou abra o aplicativo e use Abrir arquivo.

O MD Reader abre arquivos terminados em .md ou .markdown e os exibe formatados: títulos viram títulos de verdade, etapas numeradas se alinham, e nomes de arquivos ou comandos aparecem em blocos de código com destaque de sintaxe e um botão Copiar. Tabelas largas rolam para os lados em vez de espremerem, e diagramas Mermaid são desenhados como imagens. Tudo isso funciona offline, e o aplicativo não tem permissão de internet, portanto o plano nunca sai do seu celular.

Uma coisa importante: o MD Reader não se conecta ao Claude Code e não sincroniza com o seu computador. Você está lendo uma cópia. Se pedir ao Claude para revisar o plano, envie o novo arquivo novamente. As etapas para o Drive estão em como abrir arquivos .md do Google Drive.

Lendo um plano longo com conforto

Planos para alterações maiores podem ocupar várias telas. Algumas coisas facilitam a leitura:

  • O Sumário lista os títulos do plano e destaca a seção onde você está, permitindo pular direto para "Arquivos a alterar" ou "Testes".
  • A opção Buscar no documento procura por um nome de arquivo ou palavra dentro do plano.
  • O plano reabre de onde você parou, permitindo ler metade no ônibus e terminar depois.
  • Nos Ajustes de leitura (em Aa), você pode escolher um tema escuro ou sépia, um tamanho de texto maior e uma largura de página mais estreita.

Se o Claude criou outros arquivos ao longo do caminho, como anotações ou um README, o guia sobre os arquivos .md que agentes de IA criam explica quais vale a pena ler. Para abrir uma pasta inteira deles de uma vez e pesquisar em todos os documentos, você precisa da área de trabalho de pastas no MD Reader Pro, uma compra única na Google Play. A leitura de arquivos individuais é gratuita.

Fazendo anotações e enviando alterações de volta

Se o plano incluir uma lista de tarefas, você poderá marcar as caixas enquanto lê e elas serão salvas no arquivo imediatamente. Para adicionar um comentário ou alterar uma etapa, toque em Editar e digite na página formatada, sem precisar lembrar de nenhum símbolo de markdown (mais sobre edição).

Lembre-se de que isso altera apenas a cópia no seu celular. O Claude Code não verá suas anotações até que você envie o arquivo de volta ao computador e o coloque onde o Claude possa lê-lo, ou simplesmente cole seus comentários no terminal na próxima vez que estiver na sua mesa. Muitas pessoas acham que a segunda opção é suficiente: ler no celular, decidir e digitar "vá em frente, mas pule a etapa 4" ao se sentar novamente.
