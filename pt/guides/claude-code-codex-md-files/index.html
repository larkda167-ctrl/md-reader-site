O que são os arquivos .md do Claude Code e do Codex?

Atualizado: 2026-11-03

Se você delega tarefas a um agente de programação por IA como o Claude Code ou o Codex, arquivos terminados em .md começam a aparecer no seu projeto. Eles parecem confusos no Bloco de Notas, cheios de # e **. Não há nada de errado: são documentos em markdown, o mesmo formato que as assistências de IA usam para suas respostas. Os agentes usam isso porque é um texto simples que tanto pessoas quanto IAs conseguem ler.

Os arquivos que você provavelmente vai ver

Arquivo O que é
README.md Explica o que é o projeto e como executá-lo
CLAUDE.md Instruções permanentes que o Claude Code lê para o projeto
AGENTS.md Instruções permanentes para agentes, usadas pelo Codex e outros
PLAN.md, TODO.md, NOTES.md Planos, listas de tarefas e notas, quando você ou o agente decidem mantê-los
CHANGELOG.md Um registro do que mudou em cada versão

Nomes além dos três primeiros variam de projeto para projeto, então leia um se não tiver certeza de para que ele serve.

Tome cuidado com CLAUDE.md e AGENTS.md. Alterá-los muda a forma como o agente se comporta naquele projeto. Ler esses arquivos é sempre seguro.

Por que você iria querer lê-los

Estes arquivos mostram onde o agente se explica: o que ele planejou, o que fez e o que falta. Se você ignorar esses arquivos, acaba confiando apenas em um resumo no chat. Eles também costumam ser longos e mais fáceis de ler longe da sua mesa do que em um terminal.

Lendo no seu celular

Como essas ferramentas geralmente rodam em um computador, o arquivo precisa chegar ao seu celular primeiro:

  1. Envie o arquivo para você mesmo. O Google Drive, um anexo de e-mail e um cabo USB funcionam.
  2. No seu celular, abra-o com o MD Reader: toque no arquivo e escolha o MD Reader, ou use Abrir arquivo no aplicativo.

Disponível no Google Play

Títulos, tabelas, blocos de código com destaque de sintaxe, matemática e diagramas Mermaid são exibidos formatados. Metadados iniciais aparecem como um cartão, e tags como <example>, que são comuns em arquivos de instruções, são mostradas como foram escritas em vez de desaparecerem.

O MD Reader não sincroniza com o seu computador e não se conecta ao Claude Code ou ao Codex. O que você abre é a cópia que você enviou. Envie o arquivo novamente quando o agente atualizá-lo. Instruções passo a passo estão em como abrir arquivos .md do Google Drive.

Explorando uma pasta inteira

Os agentes raramente param em um único arquivo. Com o espaço de trabalho de pastas (em breve no Pro), você poderá copiar uma pasta para o seu celular, abri-la, pesquisar em todos os seus documentos e seguir links entre eles.

Alterando um plano pelo celular

Marque uma caixa de seleção em uma lista de tarefas durante a leitura e ela será salva no arquivo imediatamente. Para alterar o texto, toque em Editar e digite na página formatada, sem símbolos para lembrar (mais sobre a edição). Se o arquivo veio de um local que só permite leitura, o MD Reader pedirá para você salvar uma cópia. Para usar suas alterações no projeto, envie o arquivo de volta para o seu computador.
