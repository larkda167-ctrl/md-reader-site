O que é um arquivo .md? (E como abri-lo no celular)

Atualizado: 2026-11-03

Um arquivo terminado em .md é um arquivo markdown. O Markdown é uma forma de escrever texto formatado usando caracteres comuns, então o arquivo é apenas texto puro que qualquer dispositivo pode armazenar.

Aqui vai um pequeno exemplo. É isto que o arquivo contém:

# Lista de compras

Comprar isto **hoje**:

- Leite
- Pão
- [ ] Ligar para a padaria

Um visualizador de markdown transforma isso em uma página formatada: um título "Lista de compras" grande, a palavra "hoje" em negrito, uma lista com marcadores e uma caixa de seleção que você pode marcar.

Por que tantos arquivos são .md hoje em dia

  • Arquivos README. Quase todo projeto de software tem um README.md que explica o que ele é.
  • Aplicativos de notas. Obsidian, Logseq, Joplin e muitos outros aplicativos salvam notas como arquivos .md.
  • Assistentes de IA. ChatGPT, Claude e Gemini escrevem suas respostas em markdown. Quando você salva ou exporta uma resposta, frequentemente recebe um arquivo .md.
  • Agentes de IA para programação. Claude Code e Codex deixam arquivos .md no seu projeto, como CLAUDE.md, AGENTS.md e planos. O que esses arquivos são.
  • Documentação. Muitos manuais, wikis e anotações de cursos são escritos em markdown.

O Markdown é popular porque pode ser lido mesmo sem um visualizador, funciona em qualquer sistema e é fácil de converter para uma página da web ou PDF.

O que o markdown pode conter

  • Títulos (#, ##)
  • Texto em negrito e itálico
  • Listas com marcadores, numeradas e de tarefas
  • Links e imagens
  • Tabelas
  • Blocos de código
  • Frequentemente fórmulas matemáticas ($E = mc^2$) e diagramas (Mermaid)

Os dois últimos não fazem parte do markdown básico, então visualizadores simples os mostram como texto bruto. Um bom visualizador os renderiza.

Como ler um arquivo .md no Android

O Android não consegue formatar markdown por conta própria. Instale um visualizador de markdown e abra o arquivo com ele.

Posso apenas renomeá-lo para .txt?

Você pode, e conseguirá ler o texto. Mas verá todos os símbolos, as tabelas parecerão linhas de caracteres | e as caixas de seleção não funcionarão. Por que seu arquivo .md mostra símbolos # e ** explica a diferença.
