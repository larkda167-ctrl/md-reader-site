"Nenhum app pode abrir este arquivo" ao abrir .md: solução

Atualizado: 2026-11-08

Você toca em um arquivo .md e o Android exibe a mensagem "Nenhum app pode abrir este arquivo" (ou "Não é possível abrir o arquivo"). O arquivo está em perfeito estado; o seu celular só não tem um app registrado para Markdown.

Por que isso acontece

O Android escolhe o app com base no tipo de arquivo. Arquivos Markdown costumam ser identificados como text/markdown ou como um tipo de arquivo genérico. Quase nenhum aplicativo pré-instalado reconhece esses tipos, então o Android fica sem opções para sugerir.

Solução: instale um visualizador de Markdown

  1. Instale o MD Reader no Google Play. Ele se registra no sistema para arquivos .md e .markdown.
  2. Toque no arquivo novamente.
  3. Selecione o MD Reader (e escolha Sempre, se preferir).

Disponível no Google Play

Ainda não está funcionando?

O tipo de arquivo foi identificado incorretamente. Alguns apps enviam o Markdown como um tipo desconhecido, fazendo com que nenhum visualizador apareça na lista. Abra o MD Reader, toque em Abrir arquivo e selecione o documento pelo seletor de arquivos. Isso sempre funciona.

O arquivo está dentro de um ZIP. Extraia-o primeiro. No Files do Google (ou no app Meus Arquivos), toque no arquivo compactado e selecione Extrair.

É um anexo ou arquivo na nuvem. Baixe o arquivo ou use o menu Abrir com do aplicativo de origem. Consulte nossos guias sobre anexos de e-mail e Google Drive.

Agora ele está abrindo no app errado. Acesse Configurações → Apps, localize o app que está abrindo o arquivo e vá em Abrir por padrão → Limpar padrões. Depois, toque no arquivo novamente para escolher.

E se não for um arquivo Markdown de verdade?

Alguns programas usam a extensão .md para outros formatos, como imagens de disco antigas ou dados de jogos. Se o MD Reader exibir caracteres aleatórios em vez de texto legível, é provável que o arquivo não seja Markdown. Um arquivo Markdown autêntico é sempre composto por texto legível.
