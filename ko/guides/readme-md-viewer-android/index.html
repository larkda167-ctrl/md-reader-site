안드로이드에서 README.md 파일 보는 법

수정일: 2026-10-29

README.md는 소프트웨어 프로젝트를 설명하는 파일입니다. 무엇을 하는지, 어떻게 설치하고 쓰는지 적혀 있습니다. 마크다운으로 쓰여 있어서 휴대폰에서는 기호가 그대로 보이거나 아예 열리지 않습니다.

깃허브에 있는 README

프로젝트가 깃허브에 있다면 깃허브 웹사이트가 README를 이미 정리해서 보여 줍니다. 브라우저로 저장소 페이지를 열면 됩니다. 뷰어가 필요한 건 파일 자체를 가지고 있을 때입니다. 예를 들면 이렇습니다.

  • 프로젝트를 zip으로 내려받았을 때
  • 누군가 README를 보내 줬을 때
  • 서버나 드라이브가 파일을 원문 그대로 보여 줄 때
  • 기차나 비행기에서 오프라인으로 읽고 싶을 때

안드로이드에서 README.md 열기

  1. 마크다운 뷰어를 설치합니다. 여기서는 MD 리더를 씁니다.
  2. 내 파일에서 README.md를 찾아 누르고 MD 리더를 고릅니다.
  3. 또는 MD 리더에서 파일 열기를 누르고 README를 고릅니다.

Google Play에서 받기

zip 파일 안에 있을 때: 내 파일이나 Files 앱에서 zip을 누르고 압축 풀기를 고른 뒤, 풀린 폴더에서 README.md를 엽니다.

raw 링크로 열었을 때: 브라우저에서 README의 raw 링크를 열면 일반 텍스트로 보입니다. 길게 눌러 전체 선택 → 복사한 뒤, MD 리더에서 클립보드에서 붙여넣기를 누르세요.

이렇게 보입니다

README에는 다른 문서보다 서식이 많습니다. MD 리더는 이렇게 보여 줍니다.

  • 코드 블록: 문법 색상과 한 번에 복사하는 버튼이 붙어서 설치 명령어를 옮기기 편합니다. 휴대폰에서 코드 블록 읽기를 참고하세요.
  • 표: 옵션과 설정 표가 넓으면 옆으로 넘겨 봅니다.
  • 작업 목록: 로드맵 체크리스트가 보입니다.
  • Mermaid 다이어그램: 구조도가 그려집니다. Mermaid 다이어그램 보기를 참고하세요.
  • 콜아웃: > [!WARNING] 같은 강조 상자가 보입니다.
  • 목차: 제목으로 목차가 만들어져서 "설치" 부분으로 바로 갈 수 있습니다.

링크와 이미지

웹사이트 링크는 브라우저에서 열립니다. 프로젝트 안의 다른 파일 링크(예: docs/setup.md)는 폴더 전체가 필요하므로 지금은 그 파일을 따로 여세요. 웹 주소를 가리키는 이미지는 인터넷이 있어야 불러옵니다. MD 리더는 인터넷 권한을 요청하지 않으므로 그런 이미지는 보이지 않습니다. 주변 글은 문제없이 읽을 수 있습니다.
