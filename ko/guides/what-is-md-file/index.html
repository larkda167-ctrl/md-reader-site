.md 파일이란? 휴대폰에서 여는 방법까지

수정일: 2026-10-29

.md로 끝나는 파일은 마크다운(Markdown) 파일입니다. 마크다운은 평범한 글자로 서식을 표시하는 방법입니다. 그래서 파일 자체는 어느 기기에서나 저장할 수 있는 일반 텍스트입니다.

예를 들어 파일 안에는 이렇게 적혀 있습니다.

# 장보기 목록

**오늘** 살 것:

- 우유
- 식빵
- [ ] 빵집에 전화하기

마크다운 뷰어로 열면 정리된 화면이 됩니다. "장보기 목록"은 큰 제목으로, "오늘"은 굵은 글씨로 보입니다. 목록은 글머리표로, 마지막 줄은 누를 수 있는 체크박스로 바뀝니다.

요즘 .md 파일이 많은 이유

  • README 파일: 거의 모든 소프트웨어 프로젝트에는 프로젝트를 설명하는 README.md가 있습니다.
  • 메모 앱: Obsidian, Logseq, Joplin 같은 앱은 메모를 .md 파일로 저장합니다.
  • AI 어시스턴트: ChatGPT, Claude, Gemini는 답변을 마크다운으로 씁니다. 답변을 저장하거나 내보내면 .md 파일이 되는 경우가 많습니다.
  • 문서: 매뉴얼, 위키, 강의 노트도 마크다운으로 많이 씁니다.

마크다운이 인기인 이유는 뷰어 없이도 읽을 수 있고, 어떤 시스템에서나 열리고, 웹페이지나 PDF로 바꾸기 쉽기 때문입니다.

마크다운에 들어가는 것

  • 제목(#, ##)
  • 굵게, 기울임
  • 글머리표, 번호, 체크박스 목록
  • 링크와 이미지
  • 표
  • 코드 블록
  • 수식($E = mc^2$)과 다이어그램(Mermaid)

수식과 다이어그램은 기본 마크다운에 포함되지 않습니다. 그래서 단순한 뷰어는 기호를 그대로 보여 줍니다. 좋은 뷰어는 이것까지 그려 줍니다.

Google Play에서 받기

MD 리더는 내 파일, 다운로드, 구글 드라이브, 메일 첨부파일, 공유 메뉴에서 .md와 .markdown 파일을 엽니다. 표, 수식, 다이어그램도 보여 줍니다. 자세한 방법은 안드로이드에서 .md 파일 여는 방법에 있습니다.

확장자를 .txt로 바꾸면 안 되나요?

바꿔도 글은 읽을 수 있습니다. 다만 기호가 전부 보이고, 표는 | 기호가 늘어선 줄이 되며, 체크박스는 작동하지 않습니다. .md 파일에 # 기호가 보이는 이유에서 차이를 설명합니다.

함께 보면 좋은 가이드

  • 안드로이드에서 .md 파일 여는 방법안드로이드에는 기본 마크다운 뷰어가 없습니다. 내 파일, 다운로드, 드라이브, 카카오톡으로 받은 .md 파일을 깔끔한 문서로 여는 방법을 정리했습니다.
  • .md 파일에 #, ** 기호가 그대로 보일 때 해결법마크다운 파일을 열었더니 #, **, | 기호만 가득하다면 일반 텍스트로 열린 것입니다. 안드로이드에서 정리된 문서로 보는 방법입니다.
  • 안드로이드에서 README.md 파일 보는 법깃허브 프로젝트나 압축 파일에 들어 있는 README.md를 안드로이드 휴대폰에서 제목, 표, 코드까지 깔끔하게 읽는 방법입니다.
  • 마크다운 문법 몰라도 .md 파일 편집하는 법안드로이드에서 .md 파일을 일반 문서처럼 고치세요. 정리된 화면에 그대로 입력하면 마크다운 기호는 앱이 알아서 씁니다.
