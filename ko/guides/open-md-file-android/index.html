안드로이드에서 .md 파일 여는 방법

수정일: 2026-10-29

.md 파일은 마크다운 문서입니다. 일반 텍스트에 #, **, - 같은 기호를 섞어 제목, 굵은 글씨, 목록을 표시합니다. 안드로이드에는 이 기호를 이해하는 앱이 기본으로 들어 있지 않습니다. 그래서 .md 파일을 누르면 보통 셋 중 하나가 됩니다.

  • "이 파일을 열 수 있는 앱이 없습니다"라는 메시지가 뜹니다.
  • 텍스트 편집기가 열려 #, ** 기호가 그대로 보입니다.
  • 브라우저가 파일을 또 내려받기만 합니다.

정리된 문서로 읽으려면 마크다운 뷰어가 필요합니다.

1단계: 마크다운 뷰어 설치하기

Google Play에서 마크다운 뷰어를 설치하세요. 이 글에서는 MD 리더를 사용합니다. 무료이고, 인터넷 없이 작동하며, 인터넷 권한도 요청하지 않습니다.

2단계: 파일 열기

파일이 어디에 있든 열 수 있습니다.

내 파일·다운로드에서 열기

  1. 내 파일(삼성) 또는 Files 앱에서 .md 파일을 찾습니다.
  2. 파일을 누르고, 어떤 앱으로 열지 물으면 MD 리더를 고릅니다.
  3. 매번 MD 리더로 열고 싶다면 항상을 누릅니다.

앱 안에서 열기

  1. MD 리더를 엽니다.
  2. 파일 열기를 누릅니다.
  3. 안드로이드 파일 선택 화면에서 파일을 고릅니다. 다운로드, 내장 메모리, 구글 드라이브 같은 클라우드 앱까지 이 화면에서 찾을 수 있습니다.

다른 앱에서 공유하기

파일이나 텍스트를 공유할 수 있는 앱이라면 공유를 누르고 MD 리더를 고르세요. 클라우드, 메신저, 메모 앱 대부분에서 됩니다.

3단계: 읽고, 찾고, 고치기

파일이 열리면 제목, 표, 코드, 링크, 체크리스트가 제대로 보입니다. 이렇게 쓸 수 있습니다.

  • 목차를 열어 원하는 부분으로 바로 이동합니다.
  • 문서 안 검색으로 단어를 찾습니다.
  • 편집을 눌러 정리된 화면에서 바로 오타를 고칩니다. 마크다운 기호는 몰라도 됩니다.

그래도 안 열린다면

  • 파일 이름이 .md로 끝나지 않는 경우: 마크다운을 .txt나 .markdown으로 저장하는 앱도 있습니다. MD 리더에서 파일 열기로 여세요.
  • 카카오톡이나 메일로 받은 파일인 경우: 먼저 저장한 뒤 여세요. 카카오톡·메일로 받은 .md 파일 열기를 참고하세요.
  • "열 수 있는 앱이 없습니다"가 계속 뜨는 경우: 해결 방법을 확인하세요.

마크다운이 처음이라면 .md 파일이 무엇인지부터 읽어 보세요. 2분이면 됩니다.
