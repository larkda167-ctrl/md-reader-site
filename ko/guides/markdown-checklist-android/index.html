안드로이드에서 마크다운 체크리스트 쓰는 법

수정일: 2026-10-29

마크다운에는 할 일 목록을 쓰는 간단한 방법이 있습니다.

- [x] 항공권 예약
- [ ] 여권 갱신
- [ ] 충전기 챙기기

[ ]는 아직 안 한 일, [x]는 끝낸 일입니다. 이런 작업 목록은 README, 프로젝트 메모, 짐 목록, 공부 계획, AI가 짜 준 계획에 두루 쓰입니다.

문제는 휴대폰입니다. 대부분의 앱은 괄호를 글자 그대로 보여 주거나, 체크박스를 보여 줘도 누를 수가 없습니다.

누르면 파일에 저장되는 체크박스

MD 리더에서는 읽는 중에 체크리스트를 바로 쓸 수 있습니다.

  1. .md 파일을 엽니다.
  2. 체크박스를 누릅니다.
  3. 끝입니다. 변경 내용이 바로 파일에 저장되고, 원문의 [ ]가 [x]로 바뀝니다.

Google Play에서 받기

편집 모드에 들어갈 필요도 없고, 괄호를 볼 일도 없습니다.

새 할 일 추가하기

  1. 편집을 누릅니다.
  2. 할 일 끝에 커서를 두고 줄바꿈을 누르면 새 항목이 생깁니다.
  3. 새 체크리스트를 만들려면 빈 줄에서 /를 입력하고 체크리스트를 고릅니다.
  4. 저장을 누릅니다.

더 자세한 내용은 마크다운 몰라도 편집하는 법에 있습니다.

이렇게 쓰면 좋습니다

  • 동기화 폴더에 .md 파일로 둔 장보기·짐 목록
  • README의 프로젝트 할 일
  • 공부 계획과 읽을 책 목록
  • AI가 짜 준 계획: ChatGPT나 Claude에 "마크다운 체크리스트로 계획을 짜 줘"라고 요청한 뒤 MD 리더에 붙여 넣고 파일로 저장하세요. AI 답변을 마크다운 파일로 저장하기를 참고하세요.

동기화 폴더의 체크리스트

메모가 구글 드라이브 같은 클라우드에 있다면 그 앱의 연결 앱 메뉴로 파일을 여세요. 변경 내용이 다시 동기화되는지는 클라우드 앱에 따라 다릅니다. 구글 드라이브의 .md 파일 열기를 참고하세요.

할 일 앱 대신 마크다운을 쓰는 이유

.md 체크리스트는 그냥 텍스트입니다. 어떤 편집기, 어떤 컴퓨터, Git 같은 버전 관리에서도 쓸 수 있습니다. 앱 서비스가 끝나도 사라지지 않고, 한 문서 안에 할 일과 메모, 링크, 표를 함께 둘 수 있습니다.
