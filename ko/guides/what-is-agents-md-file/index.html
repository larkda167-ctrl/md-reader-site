AGENTS.md 파일이란? 하는 일과 적어야 할 내용

수정일: 2026-11-23

AGENTS.md는 AI 코딩 에이전트에게 주는 지시문을 적어 두는 텍스트 파일입니다. 코딩 에이전트는 Codex처럼 코드를 대신 쓰고 고쳐 주는 도구를 말합니다. 에이전트가 일을 시작하기 전에 이 파일을 읽기 때문에, 프로젝트를 어떻게 빌드하고 테스트하는지, 어떤 규칙을 지켜야 하는지 미리 알고 시작합니다.

파일은 마크다운으로 씁니다. #이나 ** 같은 기호로 글의 모양을 표시하는 간단한 방식입니다. 파일 자체가 무언가를 실행하지는 않으니 열어서 읽는 것은 안전합니다. 고칠 때는 조심하세요. 에이전트가 바뀐 내용대로 움직입니다.

무엇을 적나요

AGENTS.md 공식 사이트는 이 파일을 "에이전트를 위한 README"라고 설명합니다. README.md는 사람이 읽는 문서라서 프로젝트가 무엇이고 어떻게 시작하는지를 적습니다. AGENTS.md에는 에이전트에게만 필요한 자세한 내용, README에 넣으면 지저분해질 내용을 적습니다.

꼭 채워야 하는 항목은 없습니다. 평범한 마크다운 문서이고 제목도 마음대로 정하면 됩니다. 공식 사이트가 권하는 내용은 이렇습니다.

  • 프로젝트 개요: 무엇을 하는 프로젝트인지 몇 줄로
  • 빌드와 테스트 명령어: 에이전트가 자기 작업을 직접 확인할 수 있습니다.
  • 코드 스타일: 프로젝트에서 지키는 약속
  • 테스트 안내: 무엇이 통과해야 작업이 끝난 것인지
  • 보안 관련 주의: 조심해서 다뤄야 하는 부분

커밋과 풀 리퀘스트 규칙, 배포 절차를 넣어도 됩니다. 작게 쓰면 이런 모습입니다.

# AGENTS.md

## 명령어
- 설치: npm install
- 테스트: npm test (끝내기 전에 꼭 실행)

## 코드 스타일
- 화면에 보이는 문구는 src/i18n에 두기

## 건드리지 않기
- /generated 폴더의 파일은 스크립트가 만듭니다

어디에 두나요

프로젝트 맨 위 폴더에 둡니다. 대부분은 이것 하나로 충분합니다.

여러 부분으로 나뉜 큰 프로젝트라면 부분마다 AGENTS.md를 하나씩 둘 수 있습니다. 공식 사이트에 따르면 에이전트는 폴더 구조에서 가장 가까운 파일을 읽으므로, 가까운 쪽이 우선합니다.

파일 용도
맨 위 폴더의 AGENTS.md 프로젝트 전체에 적용할 지시문
하위 폴더의 AGENTS.md 그 폴더 안에서 작업할 때의 지시문. 그 안에서는 이쪽이 우선

대화창에 직접 입력한 요청은 둘보다 앞섭니다. 분명하게 요청하면 파일 내용보다 그 요청을 따릅니다.

어떤 도구가 읽나요

AGENTS.md는 한 제품에 묶인 파일이 아닙니다. 누구나 쓸 수 있는 공개 형식이고, 지금은 리눅스 재단 산하 Agentic AI Foundation이 관리합니다. OpenAI의 Codex, Google의 Jules, Cursor, Amp, Factory 등 여러 팀이 함께 만들었습니다.

공식 사이트에는 이 형식을 쓰는 도구가 스무 개 넘게 올라 있습니다. Codex, Cursor, Gemini CLI, GitHub Copilot의 코딩 에이전트, Aider, Zed, Windsurf, VS Code 등입니다. 도구마다 파일을 따로 만들지 않고 프로젝트 규칙을 한 번만 적어 두자는 것이 이 형식의 목적입니다. 세부 동작은 도구마다 다르니, 파일을 읽지 않는 것 같으면 그 도구의 문서를 확인하세요.

CLAUDE.md와의 관계

Anthropic의 코딩 에이전트 Claude Code에서는 CLAUDE.md가 같은 역할을 합니다. 한 프로젝트에 둘 다 있다면 서로 다른 도구에 주는 지시문이 두 벌 있는 것이니, 내용이 어긋나지 않는지 살펴보는 것이 좋습니다. CLAUDE.md는 CLAUDE.md 파일이란에서, 옆에 함께 보이는 다른 파일은 코딩 에이전트가 만드는 .md 파일 안내에서 설명합니다.

알아 둘 점

비밀번호나 API 키는 적지 마세요. 이 파일은 보통 코드와 함께 프로젝트 안에 있어서, 프로젝트를 볼 수 있는 사람이면 누구나 읽을 수 있습니다.

내용을 최신으로 유지하세요. 에이전트는 적힌 대로 믿기 때문에, 예전 테스트 명령이나 더는 지키지 않는 규칙이 남아 있으면 엉뚱한 방향으로 갑니다. 같은 실수를 두 번 바로잡게 되면 한 줄을 더하세요.

휴대폰에서 읽으려면

일반 텍스트 앱으로 열면 #과 ** 기호가 그대로 보입니다. Android에서 서식대로 읽는 방법은 이렇습니다.

  1. 파일을 휴대폰으로 보냅니다. 코딩 에이전트는 보통 컴퓨터에서 돌아가므로 Google Drive, 이메일 첨부, USB 케이블을 쓰면 됩니다.
  2. 파일을 눌러 MD 리더를 고르거나, 앱에서 파일 열기를 누릅니다.

Google Play에서 받기

제목, 표, 코드 블록이 서식대로 보이고, 목차로 원하는 부분으로 바로 갈 수 있습니다. 지시문 파일에 자주 나오는 <example> 같은 태그도 사라지지 않고 적힌 그대로 보입니다. Google Drive에서 여는 방법은 Google Drive에서 .md 파일 열기를 참고하세요.

MD 리더는 Codex를 비롯한 코딩 도구와 연결되지 않고 컴퓨터와 동기화하지도 않으므로, 지금 보는 것은 복사본입니다. 파일이 바뀌면 다시 보내세요. 편집으로 복사본을 고칠 수는 있지만, 컴퓨터로 다시 보내기 전에는 에이전트가 바뀐 내용을 볼 수 없습니다.
