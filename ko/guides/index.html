마크다운 가이드

안드로이드에서 마크다운(.md) 파일을 열고, 읽고, 고치는 방법을 짧고 실용적으로 정리했습니다.

  • 안드로이드에서 .md 파일 여는 방법안드로이드에는 기본 마크다운 뷰어가 없습니다. 내 파일, 다운로드, 드라이브, 카카오톡으로 받은 .md 파일을 깔끔한 문서로 여는 방법을 정리했습니다.
  • .md 파일이란? 휴대폰에서 여는 방법까지.md 파일은 간단한 기호로 서식을 표시한 텍스트 문서, 마크다운입니다. 무엇인지, 왜 많이 쓰는지, 안드로이드에서 어떻게 여는지 알려 드립니다.
  • ChatGPT 답변을 휴대폰에서 문서처럼 깔끔하게 보는 법ChatGPT 답변을 복사했더니 서식이 깨졌나요? 마크다운 뷰어에 붙여 넣으면 안드로이드에서도 제목, 표, 코드가 그대로 살아납니다.
  • 안드로이드에서 Claude 답변 읽고 저장하는 법Claude의 긴 답변과 문서는 마크다운으로 되어 있습니다. 안드로이드에서 정리된 화면으로 읽고 .md 파일로 보관하는 방법입니다.
  • 안드로이드에서 README.md 파일 보는 법깃허브 프로젝트나 압축 파일에 들어 있는 README.md를 안드로이드 휴대폰에서 제목, 표, 코드까지 깔끔하게 읽는 방법입니다.
  • .md 파일에 #, ** 기호가 그대로 보일 때 해결법마크다운 파일을 열었더니 #, **, | 기호만 가득하다면 일반 텍스트로 열린 것입니다. 안드로이드에서 정리된 문서로 보는 방법입니다.
  • 휴대폰에서 마크다운 표 깔끔하게 보는 법넓은 마크다운 표는 작은 화면에서 깨지기 쉽습니다. 파일이나 AI 답변 속 표를 안드로이드에서 제대로 읽는 방법입니다.
  • 안드로이드에서 마크다운 수식(LaTeX) 보는 법.md 파일이나 AI 답변 속 수식이 $...$ 기호로만 보이나요? 안드로이드에서 LaTeX 수식을 오프라인으로 그려 보는 방법입니다.
  • 안드로이드에서 Mermaid 다이어그램 보는 법마크다운 속 Mermaid 다이어그램이 코드로만 보이나요? 안드로이드에서 순서도와 시퀀스 다이어그램을 오프라인으로 그려 보는 방법입니다.
  • 마크다운 문법 몰라도 .md 파일 편집하는 법안드로이드에서 .md 파일을 일반 문서처럼 고치세요. 정리된 화면에 그대로 입력하면 마크다운 기호는 앱이 알아서 씁니다.
  • 안드로이드에서 마크다운 체크리스트 쓰는 법휴대폰에서 .md 파일의 - [ ] 할 일을 체크하세요. 체크박스를 누르면 편집 모드 없이 바로 파일에 저장됩니다.
  • 안드로이드에서 구글 드라이브의 .md 파일 여는 법구글 드라이브는 .md 파일을 일반 텍스트로 보여 주거나 미리보기를 못 합니다. 안드로이드에서 마크다운 뷰어로 정리해 여는 방법입니다.
  • 카카오톡·메일로 받은 .md 파일 여는 법 (안드로이드)카카오톡이나 Gmail, 네이버 메일로 받은 .md 파일을 휴대폰에서 원문 기호 대신 정리된 문서로 여는 방법입니다.
  • "이 파일을 열 수 있는 앱이 없습니다" .md 파일 해결법안드로이드에서 .md 파일을 열 수 있는 앱이 없다고 나오나요? 원인과 1분 만에 해결하는 방법입니다.
  • AI 답변을 마크다운 파일로 저장하는 법 (안드로이드)ChatGPT, Claude, Gemini의 좋은 답변을 휴대폰에 .md 파일로 보관하세요. 서식은 그대로, 검색도 되고, 어떤 앱에서나 열립니다.
  • 안드로이드에서 마크다운을 PDF로 바꾸는 법변환 사이트에 올리지 않고 휴대폰에서 .md 파일을 깔끔한 PDF로 만드세요. 안드로이드 기본 PDF 저장 기능을 씁니다.
  • 오프라인 마크다운 뷰어: "인터넷 권한 없음"이 중요한 이유메모와 문서는 개인적인 것입니다. 마크다운 앱이 내 파일을 밖으로 보낼 수 있는지 확인하는 법과 진짜 오프라인 뷰어의 조건을 알려 드립니다.
  • 태블릿·폴더블에서 마크다운 편하게 읽는 법큰 화면을 .md 파일에 제대로 쓰세요. 태블릿과 폴더블에서 넓은 화면 배치, 화면 분할, 읽기 좋은 줄 길이로 마크다운을 읽는 방법입니다.
  • 안드로이드에서 마크다운 다크 모드·글자 크기 설정하는 법긴 .md 문서를 눈 편하게 읽으세요. OLED용 블랙을 포함한 테마, 글자 크기, 본문 너비, 명조 글꼴을 안드로이드에서 설정하는 방법입니다.
  • 휴대폰에서 마크다운 코드 블록 읽고 복사하는 법.md 파일과 AI 답변 속 코드를 안드로이드에서 문법 색상, 가로 스크롤, 한 번에 복사하는 버튼과 함께 읽는 방법입니다.
