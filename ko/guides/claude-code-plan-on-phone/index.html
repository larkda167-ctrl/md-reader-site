클로드 코드가 세운 계획, 휴대폰에서 읽는 법

수정일: 2026-11-27

클로드 코드가 세운 계획을 휴대폰에서 보려면 컴퓨터에 저장된 계획 파일을 휴대폰으로 옮긴 뒤 마크다운 앱으로 열면 됩니다. 클로드 코드는 계획 모드에서 쓴 계획을 컴퓨터의 정해진 폴더에 남겨 두기 때문에, 할 일은 그 폴더를 찾아 파일 하나를 옮기는 것뿐입니다.

계획이란 무엇이고 어디에 저장되나

클로드 코드는 터미널(명령어를 입력하는 글자 창)에서 돌아가는 AI 코딩 도구입니다. 계획 모드에서는 프로젝트를 살펴보고 계획을 쓰지만, 아직 파일을 고치지는 않습니다. Shift+Tab을 누르거나 메시지 앞에 /plan을 붙이면 계획 모드가 됩니다. 계획을 읽어 보고 그대로 진행할지, 더 다듬을지 고르면 됩니다.

클로드 코드 설정 문서에 따르면 계획 파일은 기본으로 ~/.claude/plans에 저장됩니다. ~는 사용자 폴더를 뜻하므로 윈도우에서는 C:\Users\<사용자 이름>\.claude\plans입니다. 맥에서도 사용자 폴더 안에 있습니다. .claude처럼 점으로 시작하는 폴더는 숨겨져 있을 수 있습니다. 맥 Finder에서는 Cmd+Shift+.을 누르면 보이고, 윈도우에서는 파일 탐색기 주소창에 경로를 바로 붙여 넣으면 됩니다.

계획이 승인을 기다리는 동안에는 Ctrl+G를 눌러 컴퓨터의 기본 텍스트 편집기로 열어 볼 수도 있습니다.

계획을 프로젝트 폴더에 두기

계획을 코드 옆에서 찾고 싶다면 plansDirectory 설정을 쓰면 됩니다. 프로젝트를 기준으로 한 폴더 경로를 적는데, 예를 들어 프로젝트의 .claude/settings.json 파일에 "plansDirectory": "./plans"라고 넣으면 새 계획이 프로젝트 안 plans 폴더에 쌓입니다.

프로젝트 폴더를 이미 구글 드라이브 같은 클라우드에 동기화해 두었다면 계획도 함께 올라가서 편합니다. 경로가 프로젝트 바깥을 가리키면 클로드 코드는 이 설정을 무시하고 기본 폴더를 씁니다.

휴대폰에서 계획 열기

  1. 계획 파일을 자신에게 보냅니다. 구글 드라이브에 올리거나, 메일에 첨부하거나, USB 케이블로 복사하면 됩니다.
  2. 휴대폰에서 파일을 누르고 MD 리더를 고르거나, 앱을 열고 파일 열기를 누릅니다.

Google Play에서 받기

MD 리더는 .md나 .markdown으로 끝나는 파일을 열어 정리된 모습으로 보여 줍니다. 제목은 제목답게, 번호 매긴 단계는 가지런하게 보이고, 파일 이름이나 명령어는 색으로 구분된 코드 블록에 복사 버튼과 함께 나옵니다. 넓은 표는 옆으로 밀어서 보고, Mermaid 다이어그램은 그림으로 그려집니다. 모두 인터넷 없이 되고, 앱에 인터넷 권한 자체가 없어서 계획이 휴대폰 밖으로 나가지 않습니다.

알아 둘 점이 있습니다. MD 리더는 클로드 코드에 연결되지 않고 컴퓨터와 동기화하지도 않습니다. 지금 읽는 것은 사본입니다. 클로드에게 계획을 고치게 했다면 새 파일을 다시 보내 주세요. 드라이브로 옮기는 순서는 구글 드라이브에서 .md 파일 열기에 있습니다.

긴 계획 편하게 읽기

큰 작업일수록 계획이 몇 화면씩 길어집니다. 이럴 때 도움이 되는 기능입니다.

  • 목차에 계획의 제목들이 나오고 지금 읽는 부분이 표시됩니다. "고칠 파일"이나 "테스트" 같은 부분으로 바로 넘어갈 수 있습니다.
  • 문서 안 검색으로 파일 이름이나 단어를 찾을 수 있습니다.
  • 다시 열면 읽던 곳에서 이어집니다. 출근길에 반만 읽고 나중에 마저 읽어도 됩니다.
  • Aa 설정에서 어두운 테마나 세피아 테마, 큰 글씨, 좁은 페이지 폭을 고를 수 있습니다.

클로드가 작업하면서 메모나 README 같은 다른 파일도 만들었다면, 코딩 에이전트가 만드는 .md 파일 안내에서 어떤 걸 읽어 볼 만한지 확인해 보세요. 이런 파일이 든 폴더를 통째로 열고 모든 문서를 한 번에 검색하려면 MD 리더 Pro의 폴더 작업공간이 필요합니다. Pro는 구글 플레이에서 한 번만 사는 상품이고, 파일을 하나씩 읽는 것은 무료입니다.

메모하고 컴퓨터로 돌려보내기

계획에 할 일 목록이 있으면 읽으면서 체크박스를 눌러 둘 수 있고, 누르는 즉시 파일에 저장됩니다. 의견을 덧붙이거나 단계를 고치고 싶으면 편집을 누르고 보이는 화면에 그대로 입력하면 됩니다. 마크다운 기호를 외울 필요가 없습니다(편집 방법 더 보기).

다만 이렇게 고쳐도 바뀌는 건 휴대폰에 있는 사본뿐입니다. 파일을 컴퓨터로 다시 보내 클로드가 읽을 수 있는 곳에 두기 전까지 클로드 코드는 내용을 모릅니다. 더 간단한 방법도 있습니다. 휴대폰에서는 읽고 판단만 해 두었다가, 자리에 돌아와 터미널에 "진행해 줘, 4단계는 빼고"라고 입력하는 것입니다. 이것만으로 충분한 경우가 많습니다.
