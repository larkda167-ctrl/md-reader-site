휴대폰에서 마크다운 코드 블록 읽고 복사하는 법

수정일: 2026-10-29

마크다운에서 코드는 백틱 세 개 사이에 씁니다.

```python
def greet(name):
    return f"안녕하세요, {name}님!"
```

휴대폰에서 일반 텍스트 앱이 가장 크게 실패하는 곳이 바로 코드입니다. 줄이 중간에서 꺾이고, 들여쓰기가 망가지고(파이썬과 YAML에서는 치명적입니다), 색도 없고, 딱 필요한 부분만 골라 복사하기도 어렵습니다.

휴대폰 코드 뷰어에 필요한 것

  • 줄바꿈 없음: 긴 줄은 옆으로 넘겨 봐서 들여쓰기가 그대로 유지됩니다.
  • 문법 색상: 코드 블록에 적힌 언어(python, js, bash…)에 맞춰 색을 입힙니다.
  • 복사 버튼: 군더더기 공백이나 백틱 없이 코드 블록만 정확히 복사합니다.
  • 고정폭 글꼴: 칸이 가지런히 맞습니다.

MD 리더의 코드 블록

MD 리더는 모든 코드 블록에 문법 색상과 가로 스크롤을 적용하고, 블록 위쪽에 복사 버튼을 붙입니다.

  1. .md 파일이나 README를 열거나, 클립보드에서 붙여넣기로 AI 답변을 붙여 넣습니다.
  2. 긴 줄은 옆으로 밉니다.
  3. 블록의 복사를 누르면 복사됨 ✓이 보입니다.

이럴 때 쓰세요

  • README의 설치 명령어: Termux 같은 터미널 앱에 붙여 넣거나 컴퓨터로 보냅니다. 안드로이드에서 README.md 보기를 참고하세요.
  • AI 답변 속 코드: ChatGPT와 Claude는 코드를 코드 블록에 넣습니다. 답변을 MD 리더에 붙여 넣으면 제대로 읽고 블록 하나씩 복사할 수 있습니다. ChatGPT 답변 깔끔하게 보기를 참고하세요.
  • 설정 파일 조각(YAML, JSON): 들여쓰기가 중요한 코드입니다.
  • diff: diff 블록은 추가된 줄과 지워진 줄을 색으로 구분합니다.

팁

  • 코드에 색이 없다면 코드 블록에 언어 이름이 빠졌을 수 있습니다. ```python은 색이 입혀지고, 그냥 ```은 입혀지지 않습니다.
  • 긴 줄은 휴대폰을 가로로 돌리거나 본문 너비 → 넓게로 보세요. 편하게 읽는 설정을 참고하세요.
  • mermaid 블록은 코드 대신 다이어그램으로 그려집니다. Mermaid 다이어그램 보기를 참고하세요.
