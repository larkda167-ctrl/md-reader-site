마크다운 문법 몰라도 .md 파일 편집하는 법

수정일: 2026-10-29

대부분의 마크다운 편집기는 원문을 보여 줍니다. 제목 앞에 ##, 굵은 글씨 양쪽에 **, 표 칸 사이에 |가 있죠. 개발자에게는 괜찮지만, README의 오타 하나를 고치거나 공유 메모를 업데이트하거나 AI가 쓴 문서에 한 줄 더하고 싶을 뿐이라면 방해만 됩니다.

더 쉬운 방법이 있습니다. 워드 프로세서처럼 정리된 화면을 바로 고치는 겁니다.

정리된 화면에서 바로 편집하기

MD 리더에서는 이렇게 합니다.

  1. .md 파일을 엽니다.
  2. 편집을 누릅니다.
  3. 글 아무 곳이나 눌러 입력합니다. 제목은 제목대로, 목록은 목록대로, 표는 표대로 유지됩니다.
  4. 저장을 누릅니다. 변경 내용이 원래 파일에 저장됩니다.

기호 없이 서식 넣기

빈 줄에서 /를 입력하면 삽입 메뉴가 열립니다.

  • 제목 1, 2, 3
  • 글머리 목록, 번호 목록, 체크리스트
  • 인용, 구분선
  • 코드 블록, 표, 수식

원문이 필요할 때

깨진 표나 다이어그램을 고칠 때처럼 마크다운 원문이 필요할 때도 있습니다. 마크다운 원문으로 편집을 누르면 원문으로, 보이는 그대로 편집을 누르면 다시 정리된 화면으로 돌아옵니다.

파일이 이상하게 바뀌지 않나요?

편집기는 다른 앱도 읽을 수 있는 표준 마크다운으로 저장합니다. 파일은 그대로 일반 .md 파일이라 Obsidian, VS Code, 깃허브 등 어떤 마크다운 도구에서도 열립니다.

안전장치

  • 저장하지 않은 초안: 앱이 닫혀도 남아 있고, 다시 열면 복원할지 물어봅니다.
  • 버전 기록: 저장한 뒤 마음이 바뀌면 이전 버전으로 되돌리기를 쓰세요.
  • 읽기 전용 파일: 일부 메일 첨부파일처럼 덮어쓸 수 없는 파일은 변경 내용이 앱 안에 보관됩니다. 다른 이름으로 저장…으로 사본을 남기세요.

체크만 하고 싶다면

체크리스트는 편집 모드도 필요 없습니다. 읽는 중에 체크박스를 누르면 바로 저장됩니다. 안드로이드에서 마크다운 체크리스트 쓰기를 참고하세요.

  • 안드로이드에서 마크다운 체크리스트 쓰는 법휴대폰에서 .md 파일의 - [ ] 할 일을 체크하세요. 체크박스를 누르면 편집 모드 없이 바로 파일에 저장됩니다.
