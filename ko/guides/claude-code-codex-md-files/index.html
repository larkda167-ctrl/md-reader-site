클로드 코드·코덱스가 만드는 .md 파일, 이게 뭘까?

수정일: 2026-11-01

클로드 코드나 코덱스 같은 AI 코딩 에이전트에 일을 시키면 프로젝트에 .md로 끝나는 파일이 생깁니다. 메모장으로 열면 #과 **가 가득해서 뭔가 잘못된 것처럼 보입니다. 하지만 정상입니다. 이 파일들은 마크다운 문서이고, AI가 답변을 쓸 때 쓰는 바로 그 형식입니다. 사람과 AI가 모두 읽을 수 있는 일반 텍스트라서 에이전트가 즐겨 씁니다.

자주 보이는 파일

파일 내용
README.md 프로젝트가 무엇이고 어떻게 실행하는지 설명
CLAUDE.md 클로드 코드가 그 프로젝트에서 읽는 고정 지시 사항
AGENTS.md 코덱스 등 에이전트가 읽는 고정 지시 사항
PLAN.md, TODO.md, NOTES.md 계획, 할 일, 메모 (사용자나 에이전트가 남기기로 한 경우)
CHANGELOG.md 버전마다 무엇이 바뀌었는지 기록

앞의 세 개 말고는 프로젝트마다 이름이 다릅니다. 무슨 파일인지 모르겠으면 열어서 읽어 보면 됩니다.

CLAUDE.md와 AGENTS.md는 조심하세요. 내용을 바꾸면 그 프로젝트에서 에이전트가 일하는 방식이 바뀝니다. 읽기만 하는 것은 언제나 안전합니다.

왜 읽어 볼 만한가

이 파일들에는 에이전트가 무엇을 계획했고, 무엇을 했고, 무엇이 남았는지가 적혀 있습니다. 읽지 않으면 채팅창의 요약만 믿게 됩니다. 내용도 길어서 터미널보다 책상 밖에서 편하게 읽는 편이 낫습니다.

휴대폰에서 읽기

이런 도구는 보통 컴퓨터에서 돌아가므로 파일을 먼저 휴대폰으로 옮겨야 합니다.

  1. 파일을 자신에게 보냅니다. 구글 드라이브, 메일 첨부, USB 케이블 모두 됩니다.
  2. 휴대폰에서 MD 리더로 엽니다. 파일을 누르고 MD 리더를 고르거나, 앱에서 파일 열기를 누르면 됩니다.

Google Play에서 받기

제목, 표, 색으로 구분된 코드, 수식, Mermaid 다이어그램이 정리된 모습으로 보입니다. 앞부분 정보(front matter)는 카드로 보여 주고, 지시 파일에 자주 나오는 <example> 같은 태그도 사라지지 않고 적힌 그대로 보입니다.

MD 리더는 컴퓨터와 자동으로 동기화하지 않고, 클로드 코드나 코덱스에 연결되지도 않습니다. 지금 보는 것은 옮겨 온 사본입니다. 에이전트가 파일을 고치면 다시 보내 주세요. 자세한 순서는 구글 드라이브에서 .md 파일 열기에 있습니다.

폴더째 살펴보기

에이전트는 파일을 하나만 만들지 않는 경우가 많습니다. 출시 예정인 Pro의 폴더 작업공간을 쓰면 폴더를 휴대폰에 복사해 열고, 안의 문서를 모두 검색하고, 문서 사이의 링크를 따라갈 수 있게 됩니다.

휴대폰에서 계획 고치기

읽다가 할 일 목록의 체크박스를 누르면 바로 파일에 저장됩니다. 글을 고치려면 편집을 누르고 보이는 화면에 그대로 입력하면 됩니다. 기호를 외울 필요가 없습니다(편집 방법 더 보기). 읽기만 허용하는 앱에서 온 파일이면 MD 리더가 사본을 저장하게 안내합니다. 고친 내용을 프로젝트에 쓰려면 파일을 컴퓨터로 다시 보내 주세요.

함께 보면 좋은 가이드

  • CLAUDE.md 파일이란? 하는 일과 적어야 할 내용CLAUDE.md는 Claude Code가 세션을 시작할 때마다 읽는 지시문 파일입니다. 무엇을 적어야 하고 언제 필요한지 쉽게 알려 드립니다.
  • .md 파일이란? 휴대폰에서 여는 방법까지.md 파일은 간단한 기호로 서식을 표시한 텍스트 문서, 마크다운입니다. 무엇인지, 왜 많이 쓰는지, 안드로이드에서 어떻게 여는지 알려 드립니다.
  • .md 파일에 #, ** 기호가 그대로 보일 때 해결법마크다운 파일을 열었더니 #, **, | 기호만 가득하다면 일반 텍스트로 열린 것입니다. 안드로이드에서 정리된 문서로 보는 방법입니다.
  • 안드로이드에서 구글 드라이브의 .md 파일 여는 법구글 드라이브는 .md 파일을 일반 텍스트로 보여 주거나 미리보기를 못 합니다. 안드로이드에서 마크다운 뷰어로 정리해 여는 방법입니다.
  • 안드로이드에서 README.md 파일 보는 법깃허브 프로젝트나 압축 파일에 들어 있는 README.md를 안드로이드 휴대폰에서 제목, 표, 코드까지 깔끔하게 읽는 방법입니다.
  • 마크다운 문법 몰라도 .md 파일 편집하는 법안드로이드에서 .md 파일을 일반 문서처럼 고치세요. 정리된 화면에 그대로 입력하면 마크다운 기호는 앱이 알아서 씁니다.
