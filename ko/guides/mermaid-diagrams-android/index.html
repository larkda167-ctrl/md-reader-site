안드로이드에서 Mermaid 다이어그램 보는 법

수정일: 2026-10-29

Mermaid는 글로 다이어그램을 그리는 방법입니다. 마크다운 파일 안에서는 코드 블록처럼 보입니다.

```mermaid
flowchart LR
  A[아이디어] --> B{할 만한가?}
  B -->|예| C[만들기]
  B -->|아니오| D[접기]
```

Mermaid를 지원하는 뷰어는 이걸 진짜 순서도로 그립니다. 지원하지 않으면 코드만 보입니다.

Mermaid가 쓰이는 곳

  • README와 문서: 깃허브와 깃랩은 웹사이트에서 Mermaid를 그려 줍니다.
  • AI 답변: Claude와 ChatGPT는 구조도, 진행 과정, 일정표를 Mermaid로 자주 그립니다.
  • 메모 앱: Obsidian 등

휴대폰에서 Mermaid 다이어그램 보기

MD 리더는 인터넷 연결 없이 앱 안에서 Mermaid 다이어그램을 그립니다.

  1. .md 파일을 열거나 클립보드에서 붙여넣기로 텍스트를 붙여 넣습니다.
  2. mermaid 코드 블록이 모두 다이어그램으로 그려집니다.
  3. 다이어그램 위의 코드 보기를 누르면 원문이, 그림 보기를 누르면 다시 그림이 보입니다.

지원하는 다이어그램

Mermaid는 여러 종류의 다이어그램을 지원합니다.

  • 순서도(flowchart, graph)
  • 시퀀스 다이어그램(sequenceDiagram)
  • 클래스·상태 다이어그램
  • 간트 차트와 타임라인
  • 파이 차트
  • 마인드맵

"다이어그램을 그릴 수 없어요"가 뜰 때

다이어그램에 문법 오류가 있으면 MD 리더는 빈칸 대신 짧은 안내를 보여 줍니다. 이렇게 확인하세요.

  • 코드 보기를 눌러 원문을 봅니다.
  • 화살표, 괄호, 따옴표가 빠지지 않았는지 확인합니다. 특수 문자가 들어간 이름은 보통 따옴표로 감싸야 합니다. 예: A["1단계 (준비)"]
  • AI가 답변을 다 쓰기 전에 복사했다면 답변 전체를 다시 복사하세요.

작은 화면에서 큰 다이어그램

넓은 다이어그램은 글자가 읽히도록 원래 크기를 유지하고 옆으로 넘겨 봅니다. 복잡한 다이어그램은 휴대폰을 가로로 돌리거나 태블릿을 쓰세요. 태블릿·폴더블에서 마크다운 읽기를 참고하세요.
