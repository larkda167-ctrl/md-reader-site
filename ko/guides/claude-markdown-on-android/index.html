안드로이드에서 Claude 답변 읽고 저장하는 법

수정일: 2026-10-29

Claude는 제목, 표, 코드, 가끔은 수식이나 Mermaid 다이어그램까지 들어간 긴 답변을 자주 씁니다. 내려받을 수 있는 문서도 만들어 주는데, 이것도 .md 파일인 경우가 많습니다. 안드로이드에서는 둘 다 Claude 앱 밖에서 읽기가 불편합니다.

복사한 답변 읽기

  1. Claude 답변 아래 복사 버튼을 누릅니다. 마크다운 원문이 복사됩니다.
  2. MD 리더를 열고 클립보드에서 붙여넣기를 누릅니다.
  3. 답변이 정리된 문서로 보입니다.

사용 중인 Claude 앱에 텍스트 공유 기능이 있다면 공유에서 MD 리더를 골라도 됩니다.

Google Play에서 받기

Claude가 만든 .md 파일 열기

Claude가 준 문서를 내려받으면 보통 다운로드 폴더에 저장됩니다.

  1. 내 파일 또는 Files → 다운로드로 갑니다.
  2. .md 파일을 누르고 MD 리더를 고릅니다.

MD 리더에서 파일 열기를 누르고 다운로드에서 골라도 됩니다. 다른 방법은 안드로이드에서 .md 파일 여는 방법에 정리했습니다.

제대로 보이는 것들

Claude 답변에는 기본 마크다운보다 많은 요소가 들어 있습니다. MD 리더는 이것들을 보여 줍니다.

  • 표: 좁은 화면에서는 깨지지 않고 옆으로 넘겨 봅니다.
  • 코드 블록: 문법 색상이 입혀지고 복사 버튼이 붙습니다.
  • 수식: $...$, $$...$$ LaTeX 수식을 그려 줍니다. 마크다운 수식 보기를 참고하세요.
  • Mermaid 다이어그램: 순서도, 시퀀스 다이어그램을 기기 안에서 그립니다. Mermaid 다이어그램 보기를 참고하세요.
  • 콜아웃: > [!NOTE] 같은 강조 상자입니다.
  • 모르는 태그: <example> 같은 글자가 사라지지 않고 적힌 그대로 보입니다.

나중을 위해 보관하기

답변을 연 뒤 다른 이름으로 저장…을 누르면 원하는 곳에 .md 파일로 저장됩니다. 일반 텍스트 파일이라 나중에 어떤 마크다운 앱으로도 열 수 있고, 특정 앱에 묶이지 않습니다. 전체 과정은 AI 답변을 마크다운 파일로 저장하기에 있습니다.
