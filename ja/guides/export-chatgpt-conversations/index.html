ChatGPT の会話をエクスポートして Markdown で読む方法

更新日: 2026-11-25

ChatGPT では全チャット履歴をエクスポートできますが、Markdown ファイル形式では取得できません。プログラム向けのデータ形式である JSON による会話データと、簡易的なビューアーページが含まれた ZIP ファイルが届くため、書式付き文書として読むには、そのビューアーを使うか、各チャットを自動変換してくれるアプリにインポートする必要があります。

この記事ではその両方の方法と、1つの回答を .md ファイルとして保存する無料の簡単な方法を解説します。

エクスポート内容について

OpenAI のヘルプセンターによると、ダウンロードした ZIP には以下のものが含まれています。

  • ブラウザで開き、会話を検索できるエクスポート用ビューアー index.html
  • JSON ファイル形式の会話データ、および CSV やその他の形式の他のアカウントデータ
  • 古いエクスポートでは、ビューアーの代わりに chat.html ファイルが含まれる場合がある

.md ファイルのフォルダはありません。各回答のテキストは JSON の中にあり、Markdown の記号（#、**、|）もそのまま含まれています。テキストアプリで JSON を開くと括弧と引用符の山になってしまうため、エクスポートデータは最初は読みにくく感じられます。

エクスポートをリクエストする方法

ウェブの場合: サインインし、プロフィールメニューを開き、設定 → データコントロール → データをエクスポート の下の エクスポート を選択し、確認します。

Android の場合: ChatGPT アプリのプロフィールメニューから 設定 を開き、データコントロール → データをエクスポート を選択して確認します。アプリからウェブへ誘導された場合は、そちらで手順を完了してください。

OpenAI が挙げているいくつかの注意点:

  • データをダウンロード リンクが記載されたメール（または SMS）が届きます。到着までに最大 7 日かかる場合があります。
  • リンクは受信後 24 時間で有効期限が切れます。また、同じアカウントにサインインしている必要があります。
  • お使いの携帯電話でリンクが開かない場合は、パソコンでお試しください。
  • Business、Enterprise、ChatGPT for Healthcare のワークスペースでは、セルフサービスのエクスポートを利用できません。
  • すでに削除したチャットをエクスポートで復元することはできません。

ファイルにはすべての履歴が含まれているため、安全な場所に保管してください。

内蔵ビューアーで読む

最も簡単な方法は、OpenAI が同梱しているビューアーを使用することです。ZIP を展開し、ブラウザで index.html を開き、フォルダを選択 をタップして展開したフォルダを選びます。ブラウザ上でローカルに動作し、ファイルがアップロードされることはありません。ZIP の展開やフォルダの選択を普段から行うパソコンで行うのが一番簡単です。

Android ですべてのチャットを文書に変換する

携帯電話上で履歴を書類のように閲覧したい場合は、MD Reader Pro を使えば ZIP を直接インポートできます。展開する必要はありません。

  1. エクスポートした ZIP をスマホにダウンロードします。
  2. MD Reader を開き、右上の本アイコンをタップして ライブラリ を開き、AI チャット タブに移動します。
  3. AI チャットをインポート をタップして ZIP を選択します。

Google Playで手に入れよう

それぞれの会話が 1 つの文書になり、見出し、表、ハイライト付きコードブロック、数式が書式設定されて表示されます。AI チャット タブには独自の検索と並び替えがあり、スクラップとは別に保持されます。後から新しいエクスポートをリクエストして再度インポートすると、新しい会話が追加され、継続した会話は更新されます。どのチャットでもスクラップにコピーできます。

インポート機能は、一度限りの Pro 購入に含まれています。閲覧およびその他の基本機能は無料です。Claude のデータ エクスポート ZIP も同様の方法でインポートできます。Gemini の履歴インポートは利用できません。

MD Reader はインターネット接続を持たず、ChatGPT アカウントとも接続していません。提供されたファイルのみを読み取るため、新しいチャットを表示するには新しいエクスポートが必要です。

1 つの回答を .md ファイルとして無料で保存する

履歴全体ではなく、1 つの良い回答だけが欲しい場合は、エクスポートは必要ありません:

  1. ChatGPT の回答の下にあるコピーをタップします。
  2. MD Reader で クリップボードから貼り付け をタップします。
  3. その他 → 名前を付けて保存… をタップし、.md ファイルとして保存します。

これにより、どのアプリでも開ける本物の Markdown ファイルが手に入ります。アシスタントにあらかじめ回答を整理してもらうなどのその他のヒントについては、AI の回答を markdown として保存する方法 をご覧ください。返信を書式設定された状態で読みたいだけの場合は、スマホで ChatGPT の markdown を見る をご覧ください。

Claude の場合は？

Claude もデータのエクスポートを提供していますが、Anthropic のヘルプセンターによると、iOS や Android アプリからは開始できないとのことです。ウェブまたはデスクトップアプリの 設定 → プライバシー → データをエクスポート をご利用ください。ダウンロードリンクはメールで届き、作成後 24 時間で期限が切れます。元々アップロードしたファイルはエクスポートに含まれません。日々の生活の中でスマホで Claude の返信を読むには、Android での Claude の markdown をご覧ください。
