Android で Markdown を画像として共有する方法

更新日: 2026-11-25

Markdown を画像として共有するには、フォーマットされた状態で表示するアプリでドキュメントを開き、生のテキストを送信する代わりに、整形されたページを画像としてエクスポートします。受け取る相手は、特別なアプリがなくても、見出し、表、リストが綺麗に整った状態で見ることができます。

これは、ほとんどのチャットアプリが Markdown を理解しないために重要です。Markdown は、AI アシスタントや多くのメモアプリで使用されているプレーンテキスト形式で、# が見出しをマークし、** が太字にします。これをグループチャットに貼り付けると、友だちは記号の壁を受け取ることになります。画像であれば、どのスマホでも同じように見えます。

Markdown を画像として送信する理由

画像を使用すると、いくつかの一般的な問題が一度に解決します。

  • フォーマットが維持されます。 表、チェックリスト、コードブロックが | や - の文字としてではなく、見たままの姿で表示されます。
  • 誰も何もインストールする必要がありません。 すべてのメッセンジャーアプリで写真を表示できます。
  • チャット内で読みやすくなります。 長い貼り付けられたメッセージや開かなければならないファイルをスクロールするよりも、ユーザーは画像を簡単にスクロールできます。

デメリットは、受け取った側が画像内のテキストをコピーしたり検索したりできない点です。言葉を再利用する必要がある場合は、代わりにテキストやファイルを送信してください（詳細は後述）。

ドキュメントを画像として共有する方法

Android では、MD Reader を使えば数回タップするだけでこれが可能です。

  1. ドキュメントを開きます。.md ファイルをタップして MD Reader を選択するか、アプリ内のファイルを開くを使用します。ChatGPT、Claude、または Gemini からコピーした回答には、貼り付けて文書を作成を使用します。
  2. メニュー（⋮）を開き、共有をタップしてから画像として共有をタップします。
  3. ドキュメントがページに分割され、サムネイルとして表示されます。必要なページをタップするか、すべて選択またはクリアを使用します。
  4. 共有をタップし、KakaoTalk や WhatsApp などの送信先アプリを選択します。選択したページがまとめて複数の画像として送信されます。

Google Playで手に入れよう

フォーマットされたバージョンがどのように見えるか確信が持てない場合は、ChatGPT の回答をスマホで読みやすい Markdown として表示する方法ガイドをご覧ください。

ページが分割される仕組み

MD Reader はドキュメントをスマホの画面サイズのページに分割するため、各画像がスマホに収まります。段落の途中で切れることはないため、文が2枚の写真に分断されることはありません。

これが、ページ選択が便利である理由です。冒頭の概要と1つの表だけが重要である場合は、その2つを選択して残りは除外します。他のユーザーは長いスクロールではなく、必要なものを正確に入手できます。

無料版と Pro 版の違い

画像としての共有は無料で利用できますが、一度に最大5ページまで、各画像に小さな「MD Reader」のマークが入るという2つの制限があります。Google Play で一度購入する買い切り型の MD Reader Pro では、これらの制限が両方とも解除され、マークなしで任意の数のページを送信できるようになります。

時々数ページだけ必要な場合は、無料版で十分です。長いドキュメントの場合も、5ページずつに分けて送信できます。

テキストまたは PDF の方が適している場合

画像が常に最適な選択肢とは限りません。

  • テキストとして共有すると、Markdown そのものが送信されます。相手がコンテンツを編集したり、Markdown を理解する別のアプリに貼り付けたりする場合に使用します。
  • PDF を使用すると、印刷したりメールに添付したりできる1つのファイルにすべてがまとめられます。MD Reader では、印刷 / PDF に保存は Pro 機能です。Android で Markdown を PDF に変換する方法をご覧ください。
  • ファイル自体は、パソコンで作業を続けるすべての人に最適です。

送信する前に確認すべきこと

  • Web 上の画像は表示されません。 MD Readerにはインターネット権限がないため、Web アドレスを指しているドキュメント内の画像は読み込まれず、共有される画像にも含まれません。ウェブサイトへのリンクのみの画像は、言葉で説明するのが最適です。
  • サムネイルを確認してください。 共有をタップする前に、選択したページを一通り確認し、不足しているものや誤って含まれているものがないことを確認してください。
  • 個人的な詳細。 画像は簡単に転送でき、取り消すのが困難です。共有するつもりのなかった名前、電話番号、住所などがページに含まれていないか確認してください。

後で共有するために AI の回答を収集する場合は、まず1つの場所にまとめておくことができます。AI チャットの回答を Markdown ファイルとして保存する方法ガイドでその方法を説明しています。
