.md ファイルとは？ Android スマホで開く方法

更新日: 2026-11-03

.md で終わるファイルは Markdown ファイルです。Markdown は通常の文字を使って書式付きテキストを作成する方法であり、ファイルはどのようなデバイスでも保存できる単なるプレーンテキストです。

簡単な例を見てみましょう。ファイルの内容は以下のようになっています。

# 買い物リスト

**今日**買うもの:

- 牛乳
- パン
- [ ] パン屋に電話する

Markdown ビューアを使用すると、これが「買い物リスト」という大きな見出し、太字の「今日」、箇条書きリスト、チェックを入れられるチェックボックスといった書式付きのページに変換されます。

最近 .md ファイルが急増している理由

  • README ファイル。 ほとんどのソフトウェアプロジェクトには、内容を説明する README.md が含まれています。
  • メモアプリ。 Obsidian、Logseq、Joplin などの多くのアプリが、メモを .md ファイルとして保存します。
  • AI アシスタント。 ChatGPT、Claude、Gemini は Markdown で回答を作成します。回答を保存またはエクスポートすると、多くの場合 .md ファイルになります。
  • AI コーディングエージェント。 Claude Code や Codex は、CLAUDE.md、AGENTS.md、計画書などの .md ファイルをプロジェクトに残します。これらのファイルの詳細についてはこちらをご覧ください。
  • ドキュメント。 多くのマニュアル、Wiki、講義ノートが Markdown で書かれています。

Markdown が人気な理由は、ビューアがなくても読みやすく、あらゆるシステムで動作し、ウェブページや PDF に簡単に変換できるからです。

Markdown で記述できる内容

  • 見出し (#, ##)
  • 太字と斜体のテキスト
  • 箇条書き、番号付きリスト、チェックリスト
  • リンクと画像
  • テーブル
  • コードブロック
  • 数式 ($E = mc^2$) や図 (Mermaid) が含まれることもあります

最後の2つは基本的な Markdown には含まれていないため、シンプルなビューアでは生のテキストとして表示されてしまいます。優れたビューアであればこれらを綺麗に描画します。

Android で .md ファイルを読む方法

Android には標準で Markdown の書式を整える機能がありません。Markdown ビューアをインストールして、そのアプリでファイルを開いてください。

Google Playで手に入れよう

MD Reader は、「ファイル」アプリ、「ダウンロード」、Google Drive、メールの添付ファイル、共有メニューなどから .md ファイルや .markdown ファイルを開くことができます。また、テーブル、数式、図の描画にも対応しています。詳しい手順は Android で .md ファイルを開く方法をご覧ください。

.txt に名前を変更するだけではダメですか？

変更してもテキストを読むことは可能です。しかし、すべての記号が表示されてしまい、テーブルは | 文字の行のように見え、チェックボックスも機能しません。.md ファイルに # や ** などの記号が表示される理由で、その違いを詳しく説明しています。
