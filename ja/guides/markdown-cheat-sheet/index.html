Markdownチートシート：基本記法とコピーできる実例

更新日: 2026-11-27

Markdown（マークダウン）は、見出しに #、太字に **、箇条書きに -、表に | といったシンプルな記号を使ってテキストを装飾します。このチートシートでは、広く使われているGitHub Flavored Markdown（GFM）に準拠した記法と、そのままコピーして使える実例をまとめました。

Markdownを初めて使う方は、.mdファイルとは何かで成り立ちや特徴を確認できます。紹介している記法はすべてプレーンテキストなので、普段お使いのメモ帳アプリでも入力可能です。

見出しと段落

行の先頭に1〜6個の # を置き、その後に半角スペースを入れます。# が1個だと最も大きな見出しになり、6個で最も小さな見出しになります。

# 旅行計画
## 1日目
### 午前

段落と段落の間に空行を入れると、新しい段落として扱われます。一度Enterキーを押しただけの単なる改行は、.md ファイルでは通常1つの行としてつながって表示されます。改行を強制したい場合は、行末に半角スペースを2つ入れるか、バックスラッシュ（\）を置きます。

太字・斜体・取り消し線

**太字**  *斜体*  ***太字かつ斜体***  ~~取り消し線~~

強調にはアンダースコア（__太字__、_斜体_）も使えます。プレーンテキストとしても読みやすさを保つため、どちらか一方の書き方に統一するのがおすすめです。

リストとチェックリスト

箇条書きリストには -、*、+ を使い、番号付きリストには数字とピリオドを使います。階層を下げたい（インデントしたい）場合は、上の行の文字の位置に合わせて字下げします。

- パン
- 果物
  - りんご
  - なし

1. 電車を予約する
2. 荷造りをする

チェックリスト（タスクリスト）は、箇条書きの後に角括弧を付けます。未完了は [ ]（中に半角スペース）、完了は [x] と書きます。

- [ ] 銀行に電話する
- [x] 家賃を振り込む

リンクと画像

リンクは、表示テキストを角括弧 [] で囲み、その直後にURLを丸括弧 () で続けます。画像は先頭に ! を付け、角括弧の中には代替テキスト（説明文）を入れます。

[ガイドを読む](https://example.com/guide)
![ルートマップ](route.png)

コード

短いコードやファイル名などのインラインコードは、バッククォート1つで囲みます（`notes.md`）。複数行のコードブロックにするには、前後の行をバッククォート3つで囲みます。最初のバッククォート3つの直後に言語名を書くと、コードに色が付きます（シンタックスハイライト）。

```python
print("hello")
```

表（テーブル）

列の区切りには | を使います。2行目のハイフンでヘッダー行とデータを区切り、コロンの位置で配置（左寄せ :---、中央揃え :---:、右寄せ ---:）を指定できます。表の前には空行を入れてください。

| 品名   | 価格 |
| :---   | ---:  |
| コーヒー | 350  |
| ケーキ   | 400  |

元のテキスト上で縦の線をきれいに揃える必要はありません。セル内で文字として | を使いたいときは、\| とエスケープします。

引用・コールアウト・脚注

行頭に > を置くと引用になります。引用の1行目に種類を指定すると、枠線で強調されたコールアウト（アラート表示）になります。GitHubでは NOTE、TIP、IMPORTANT、WARNING、CAUTION の5種類に対応しています。

> [!WARNING]
> 編集する前にファイルのバックアップを取ってください。

脚注は、本文中のマーカーと、説明文の2つの部分で構成されます。説明文はファイル内のどこに書いても、自動的にドキュメントの末尾にまとめて表示されます。

美術館は9時に開館します。[^1]

[^1]: 月曜日は休館です。

スマホで仕上がりを確認する

記法を身につける一番の近道は、装飾が適用された見た目を確認しながら書くことです。Androidで .md ファイルを開いたときに # や ** などの記号がそのまま見えている場合、そのアプリは装飾のない単なるテキストとして表示しています（原因はこちら）。

MD Reader は、このページで紹介したすべての構文を無料で整形表示します。横スクロールできる表、タップして切り替えられるチェックリスト、ハイライトと「コピー」ボタン付きのコードブロック、> [!NOTE] などのコールアウト、脚注にも対応しています。クリップボードから貼り付け をタップすれば、このページの例をすぐに試せますし、手元のファイルを開くこともできます。

Google Playで手に入れよう

記号を無理に暗記する必要もありません。編集 をタップして「見たまま編集」モードを使えば、書式設定された画面上で直接入力できます。/ を入力するだけで、見出し、リスト、チェックリスト、引用、区切り線、コードブロック、表などを簡単に追加できます。記号を直接確認したいときは、Markdown 原文で編集 に切り替えることも可能です。詳しくは記法を覚えずにMarkdownを編集する方法をご覧ください。

なお、MD Readerにはインターネットへのアクセス権限がないため、Web上のURLを指定した画像は読み込まれません。テキスト、表、コードなどの表示には一切影響ありません。
