Markdown ファイルで # や ** が消えない理由と対策

更新日: 2026-11-04

.md ファイルを開いたときに、次のような表示になることがあります。

## Meeting notes
**Decision:** ship on *Friday*
| Owner | Task |
|---|---|
| Sam | Release |

ファイルが壊れているわけではありません。プレーンテキストを表示するアプリで開いているため、装飾の代わりに Markdown の記号がそのまま見えている状態です。

記号の意味

表示される記号 意味
# Title, ## Section 見出し
**text** 太字
*text* or _text_ 斜体
- item 箇条書きリスト
- [ ] task チェックリスト
[text](https://…) リンク
| a | b | の行 テーブル
``` で囲まれた行 コードブロック
$x^2$ 数式

解決方法：Markdown ビューアーで開く

Markdown ビューアーは、記号を読み取って実際の見出し、太字、テーブル、タップ可能なチェックリストとしてきれいに表示します。

  1. Google Play から MD Reader をインストールします。
  2. ファイルを再度開き、MD Reader を選択します。スマートフォンが常にテキストアプリで開いてしまう場合は、下記の手順を確認してください。

Google Playで手に入れよう

ファイルがいつも間違ったアプリで開いてしまう場合

Android は「常にこのアプリを使う」で選択したアプリを記憶します。これを変更するには、次の手順を行います。

  1. 設定 → アプリ に移動し、現在 .md ファイルを開いているアプリ（テキストエディターやブラウザなど）を見つけます。
  2. デフォルトで開く（または 初期設定で開く）→ デフォルト設定を削除 をタップします。
  3. もう一度 .md ファイルをタップします。Android がどのアプリを使用するか尋ねるので、MD Reader を選択します。

メニュー名はスマートフォンメーカーによって多少異なります。この設定を行わなくても、MD Reader 内から ファイルを開く を使ってファイルを開くことができます。

ファイルではなく AI アプリのテキストの場合

ChatGPT や Claude から回答をコピーして記号が表示される場所に貼り付けてしまった場合は、代わりに クリップボードから貼り付け を使って MD Reader に貼り付けてください。ChatGPT の回答をスマホで整形して読むをご覧ください。

記号なしで編集したい場合

ドキュメントを変更するために Markdown を覚える必要はありません。MD Reader では、編集 をタップして、フォーマットされたページ上で直接入力できます。記号は自動的に処理されます。構文を使わずに Markdown を編集するをご覧ください。
