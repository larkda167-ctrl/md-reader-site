スマホでMarkdownのコードを読む・ワンタップでコピーする方法

更新日: 2026-11-09

Markdownでは、コードは3つのバッククォートで囲んで記述します。

```python
def greet(name):
    return f"Hello, {name}!"
```

スマホの一般的なテキストアプリでは、コードの表示が崩れやすくなります。画面端で勝手に改行されてインデントが乱れ（PythonやYAMLでは特に問題になります）、ハイライトも付かず、コピーしたい範囲だけを指先で選択するのも困難です。

スマホのコードビューアに求められる機能

  • 自動改行しないこと。 長い行も横スクロールできるため、インデントが崩れません。
  • シンタックスハイライト。 コードブロックに指定された言語（python、js、bash など）に応じて見やすく色分けされます。
  • 専用のコピーボタン。 余計な空白やバッククォートを含めず、コードの中身だけを正確にコピーできます。
  • 等幅フォント。 桁位置が崩れず綺麗に並びます。

MD Reader のコードブロック表示

MD Reader では、バッククォートで囲まれたコードブロックがシンタックスハイライト付きで表示され、横スクロールに対応し、ヘッダーにコピーボタンが配置されます。

  1. .md ファイルや README を開くか、クリップボードから貼り付けでAIの回答を取り込みます。
  2. 長いコード行は左右にスワイプして確認できます。
  3. コードブロック上のコピーをタップします。

よくある活用例

  • README のインストールコマンド。 コピーして Termux などの端末エミュレータに貼り付けたり、PCに転送したりできます。AndroidでREADME.mdを読む方法もご覧ください。
  • AIの回答に含まれるコード。 ChatGPT や Claude はコードをコードブロックで出力します。MD Reader に貼り付ければ整形された状態で読め、必要なコードだけをワンタップでコピーできます。ChatGPTの回答をスマホできれいに読む方法も参照してください。
  • 設定ファイル。 インデントの正確さが求められる YAML や JSON の確認に役立ちます。
  • 差分（Diff）。 diff ブロックでは追加行と削除行が分かりやすく色分けされます。

ヒント

  • コードに色が付かない場合、コードブロックの先頭に言語名が抜けている可能性があります。```python のように記述するとハイライトされますが、言語名のない ``` では色分けされません。
  • 長い行が多いときは、スマホを横向きにするか、表示設定で本文の幅 → 広いに設定すると快適です。快適に読むための表示設定をご覧ください。
  • mermaid ブロックはコードではなく図として描画されます。詳しくはAndroidでMermaidの作図を表示するをご覧ください。
