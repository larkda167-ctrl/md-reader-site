Android の Markdown で LaTeX 数式を表示する方法

更新日: 2026-11-05

Markdown 自体には数式の構文がありません。そのため、多くのツールではドル記号の間に LaTeX を記述します。

インライン: $E = mc^2$

ブロック:

$$
\int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}
$$

数式をサポートしていないビューアでは、ドル記号やバックスラッシュ、中括弧がそのまま表示されてしまいます。講義ノートや研究のまとめ、数式だらけの AI の回答を見る際にはこれが問題になります。

Markdown で LaTeX を目にする場面

  • AI の回答。 ChatGPT、Claude、Gemini は数式を LaTeX で記述します。回答をコピーするとソースコードがそのまま取得されます。
  • 学習ノート。 Obsidian や Notion のエクスポート、Jupyter 形式のツールで作成されたノート。
  • テクニカルな README やドキュメント。

Android で数式をレンダリングする

MD Reader は、アプリに組み込まれた高速な数式レンダラーである KaTeX を使用して LaTeX をレンダリングします。インターネット接続なしで動作します。

  1. .md ファイルを開くか、クリップボードから貼り付けをタップして AI の回答を貼り付けます。
  2. インライン数式（$...$）は文中に描画され、ブロック数式（$$...$$）は中央揃えの独立した行として表示されます。

Google Playで手に入れよう

サポートされている構文

KaTeX は、ノートや AI の回答でよく見かけるほとんどの構文をカバーしています。

  • 分数、根号、総和、積分: \frac、\sqrt、\sum、\int
  • ギリシャ文字と記号: \alpha、\infty、\leq
  • 行列: \begin{pmatrix} ... \end{pmatrix}
  • 整列された数式: \begin{aligned} ... \end{aligned}

数式にタイポがあっても、ドキュメントの残りの部分は正常にレンダリングされ、エラーのある数式も表示されるため、すぐに見つけて修正できます。

ヒント

  • 長い数式は画面からはみ出すことなく、横スクロールできます。
  • ダークモードでも数式は正しく表示されます。快適な表示設定をご覧ください。
  • 技術的な回答では、数式の近くに図が表示されることがよくあります。MD Reader は図の描画にも対応しています。Android での Mermaid 図をご覧ください。

数式を保存する

数式が AI チャットからのものである場合は、.md ファイルとして保存しておくと、いつでも読みやすく検索可能な状態を維持できます。AI の回答を Markdown として保存する方法をご覧ください。
