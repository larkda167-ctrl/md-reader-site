Claude Codeの計画（plan）をスマホで読む方法

更新日: 2026-11-27

Claude Codeが作成した計画（plan）をスマホで確認するには、パソコンからファイルをスマホへ転送し、Markdownリーダーで開きます。Claude Codeはplanモードで作成した計画ファイルをPC内の特定フォルダーに保存するため、フォルダーを見つけてファイルをスマホに移すだけで読めるようになります。

計画（plan）とは？Claude Codeの保存先はどこ？

Claude Codeは、ターミナル（コマンドを入力する画面）で動くAIコーディング支援ツールです。planモードでは、プロジェクト内を確認して実行計画を作成しますが、まだ実際のコード変更は行いません。planモードにするには、Shift+Tab を押すか、メッセージの先頭に /plan と入力します。生成された計画を読んで、そのまま進めるか、さらに検討を続けるかを選択できます。

Claude Codeの設定ドキュメントによると、計画ファイルは標準で ~/.claude/plans に保存されます。~ はホームフォルダーを表しているため、Windowsなら C:\Users\<ユーザー名>\.claude\plans、Macならユーザーフォルダー内です。.claude はドットから始まる隠しフォルダーなので、MacのFinderでは Cmd+Shift+. を押して表示させ、Windowsではエクスプローラーのアドレスバーにパスを直接貼り付けると開けます。

また、計画の承認待ちの画面で Ctrl+G を押すと、パソコンの標準テキストエディターで計画ファイルを開くこともできます。

計画ファイルをプロジェクト内に保存する設定

計画ファイルをコードと同じプロジェクト内で管理したい場合は、Claude Codeの plansDirectory 設定が便利です。プロジェクト内の .claude/settings.json に、例えば "plansDirectory": "./plans" のように相対パスを指定すると、新しい計画はプロジェクト配下の plans フォルダーに保存されます。

プロジェクトフォルダーをGoogle Driveなどのクラウドと同期している場合、計画ファイルも自動でクラウドに保存されるため、スマホへの転送が簡単になります。なお、プロジェクト外を指すパスを指定した場合は無視され、標準のフォルダーが使われます。

スマホで計画ファイルを開く手順

  1. 計画ファイルをスマホに送信します。Google Driveへのアップロード、メールへの添付、USBケーブルでの転送など、どの方法でも構いません。
  2. スマホ上でファイルを開く際にMD Readerを選択するか、アプリを開いてファイルを開くからファイルを選択します。

Google Playで手に入れよう

MD Readerは .md や .markdown のファイルを開き、きれいに整形して表示します。見出しは見出しらしく表示され、番号付きリストも揃い、ファイル名やコマンドはシンタックスハイライト付きのコードブロック（コピーボタン付き）で表示されます。横長の表は縮むことなく横スクロールでき、Mermaidの図も画像として描画されます。すべてオフラインで動作し、アプリにインターネット接続権限はないため、計画の内容がスマホの外へ漏れる心配はありません。

注意点として、MD ReaderはClaude Codeと直接通信したり、PCと自動同期したりはしません。スマホ上で開いているのはあくまでファイルのコピーです。Claudeに計画の修正を指示した場合は、新しくできたファイルを再度スマホに送ってください。Driveからの手順はGoogle Driveから.mdファイルを開く方法で解説しています。

長い計画を快適に読み進める

大規模な改修計画は、何画面分にも及ぶ長い文書になることがあります。以下の機能を使うと快適に読み進められます。

  • 目次: 計画内の見出しを一覧表示し、今読んでいる位置をハイライトします。「変更対象ファイル」や「テスト計画」などの章へすぐにジャンプできます。
  • 文書内を検索: 計画内の特定のファイル名やキーワードを素早く探せます。
  • 前回閉じた位置からそのまま再開できるため、移動中に途中まで読み、後から続きを読めます。
  • 表示設定（Aaアイコン）: ダークやセピアのテーマを選べるほか、文字サイズを大きくしたり、本文の幅を狭く調整したりできます。

Claudeが作業メモやREADMEなど他のファイルも同時に作成した場合は、AIコーディングツールが作成する.mdファイル解説をご覧ください。フォルダー全体を開いて全文書を一括検索したい場合は、Google Playの買い切り版「MD Reader Pro」のフォルダーワークスペース機能で利用可能です。単一ファイルの閲覧は無料版のままで行えます。

メモを書き込んでPCへ戻す

計画ファイルにチェックリストが含まれている場合、閲覧中にチェックボックスをタップするだけで、その変更が即座にファイルへ保存されます。コメントを追加したり手順を書き換えたりしたい場合は、編集をタップすると、Markdown記法を意識せず見たまま直接テキストを入力できます（詳しくは記法なしでMarkdownを編集するを参照）。

ただし、編集されるのはスマホ内のコピーだけです。スマホで書いたメモをClaude Codeに認識させるには、ファイルをPCに戻して元の場所に配置するか、デスクに戻った際にターミナルへ直接要点を貼り付けて指示を出します。スマホでじっくり読んで方針を決め、PCに戻ってから「手順4はスキップして進めて」とターミナルに入力する、という使い分けだけでも十分快適です。
