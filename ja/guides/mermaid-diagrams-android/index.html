Android で Mermaid の図を表示する方法

更新日: 2026-11-05

Mermaid は、テキストを使って図を描画するための仕組みです。Markdown ファイル内では、以下のようなコードブロックとして記述されます。

```mermaid
flowchart LR
  A[アイデア] --> B{価値はあるか？}
  B -->|はい| C[作る]
  B -->|いいえ| D[やめる]
```

Mermaid に対応したビューアを使えば、これが実際のフローチャートに変換されます。対応していないアプリでは、コードのまま表示されてしまいます。

Mermaid が使われる場面

  • GitHub や GitLab の README やドキュメント (ウェブサイト上では Mermaid がレンダリングされます)
  • AI の回答。 Claude や ChatGPT は、アーキテクチャやプロセス、タイムラインの図を Mermaid で描くことがよくあります
  • Obsidian などのノートアプリ

スマホで Mermaid の図を表示する

MD Reader は、インターネット接続なしで、アプリ内に Mermaid の図を描画します。

  1. .md ファイルをファイルを開くで開くか、クリップボードから貼り付けを使ってテキストを貼り付けます。
  2. すべての mermaid コードブロックが図として描画されます。
  3. 図の上部にあるコードを表示をタップするとソースコードを確認でき、Show diagram をタップすると図の表示に戻ります。

Google Playで手に入れよう

サポートされている図の種類

Mermaid は、以下をはじめとする多くの図の種類をサポートしています。

  • フローチャート (flowchart, graph)
  • シーケンス図 (sequenceDiagram)
  • クラス図および状態図
  • ガントチャートとタイムライン
  • 円グラフ
  • マインドマップ

「この図を描画できません」と表示される場合

図に構文エラーがある場合、MD Reader は空白にする代わりに短いメッセージを表示します。その場合の対処法:

  • コードを表示をタップしてソースを確認します。
  • 矢印、括弧、引用符の抜けがないか確認します。特殊文字を含むラベルには通常、引用符が必要です (A["ステップ (1)"])。
  • AI チャットの生成途中でコピーした場合は、回答の全体をもう一度コピーし直してください。

小さな画面で大きな図を見る幅の広い図は縮小されず、そのまま横スクロールできるため、ラベルが読みやすくなります。複雑な図の場合は、スマホを横向きにするか、タブレットを使用してください。タブレットや折りたたみ端末での Markdown の読み方もあわせてご覧ください。
