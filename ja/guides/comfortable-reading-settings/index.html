Android での Markdown のダークモードと文字サイズ

更新日: 2026-11-10

仕様書、学習ノート、3,000語の AI の回答などの長い Markdown 文書は、文字が小さかったり、まぶしい白背景だったり、画面いっぱいに長い行が続いたりすると読むのが大変です。いくつかの設定を変更するだけで、読みやすさが大きく変わります。

テーマ

MD Reader には5つのテーマがあります：

テーマ おすすめの用途
Auto スマホのライト/ダーク設定に合わせる
Light 日中、印刷用
Sepia 長時間の読書、白よりも温かみがありソフト
Dark 夜間や暗い場所
Black OLED 画面：完全な黒でバッテリーを節約し、夜間に最も見やすい

コードブロック、数式、図もテーマに合わせて色が変わるため、いつでも読みやすさを維持できます。

Google Playで手に入れよう

文字サイズ

表示設定 → 文字サイズ を開き、スマホを顔に近づけずに読める大きさに調整します。この設定はすべての文書に適用されます。

本文の幅

本文の幅では、1行あたりの長さを設定できます：

  • 狭い / 普通： 文章を読むのに快適な行の長さ
  • 広い / 最大： 表、コード、図を表示するスペースを広く確保

スマホで Markdown の表を読むもご覧ください。

フォント

すっきりとした画面にしたい場合は サンセリフ、長文で本のような読書感を味わいたい場合は セリフ を選択できます。

長文文書のナビゲーション

  • 目次： 任意の見出しにジャンプできます。現在のセクションがハイライト表示されます。
  • 読書進捗バー： 文書のどこまで読んだかを確認できます。
  • 文書内を検索： 特定の単語を検索できます。
  • 続きから読む： すどの文書も、前回中断した場所から開き直します。

言語

アプリのインターフェースは 27 言語に対応しています。デフォルトではスマホの言語設定に従いますが、表示設定 → 言語 から変更することも可能です。

タブレットや折りたたみ端末をお使いですか？大画面で Markdown を読むをご覧ください。
