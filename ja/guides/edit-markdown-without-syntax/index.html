Markdown の書き方を知わずにファイルを編集する方法

更新日: 2026-11-03

ほとんどの Markdown エディターでは、見出しの前に ##、太字の周りに **、表のセル間に | といったプレーンテキストのソースが表示されます。開発者にとっては問題ありませんが、README の誤字を修正したり、共有ノートを更新したり、AI が作成した文書に1行追加したりするだけのときには、こうした記号がかえって邪魔になります。

もっと簡単な方法があります。ワープロソフトで文書を編集するように、装飾されたページを直接編集するのです。

装飾されたページでの編集

MD Reader では以下の手順で行います：

  1. ファイルを開く
  2. 編集をタップします。
  3. テキスト内の任意の場所をタップして入力を開始します。見出しは見出しのまま、リストはリストのまま、表は表のまま維持されます。
  4. 保存をタップします。変更内容が元のファイルに書き込まれます。

Google Playで手に入れよう

記号を使わずに書式を追加する

空の行で / を入力すると、挿入メニューが開きます：

  • 見出し 1、2、3
  • 箇条書きリスト、番号付きリスト、チェックリスト
  • 引用、区切り線
  • コードブロック、表、数式

ソースを確認・編集したいとき

壊れた表や図の修正など、生データの Markdown が必要な場合もあります。Markdown 原文で編集を選択するとプレーンテキストに切り替わり、見たまま編集を選択すると元の表示に戻ります。

ファイルが変に変更されることはありませんか？

このエディターは、他のアプリでも読み取れる標準的な Markdown を書き込みます。ファイルはプレーンな .md ファイルのままなので、Obsidian、VS Code、GitHub、その他の Markdown ツールでも開くことができます。

安全機能

  • 保存されていない下書きはアプリが閉じても保持され、復元することができます。
  • バージョン履歴： 保存後に考えが変わった場合は、以前のバージョンを復元を使用します。
  • 読み取り専用ファイル（一部のメール添付ファイルなど）は上書きできません。変更内容はアプリ内に保持され、名前を付けて保存…を使用してコピーを保存できます。

チェックボックスのチェックだけを入れたい場合

チェックリストのために編集モードにする必要さえありません。読んでいる最中にチェックボックスをタップするだけで保存されます。Android での Markdown チェックリストもご覧ください。
