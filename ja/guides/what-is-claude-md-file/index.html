CLAUDE.md とは？その役割と書き方・作り方

更新日: 2026-11-03

CLAUDE.md ファイルは、Anthropic のコーディングエージェントである Claude Code 用の定型指示が書かれたプレーンテキストファイルです。Claude Code はセッションの最初にこれを読み込むため、テストコマンドやプロジェクトのルールを毎回繰り返し指示する必要がなくなります。

Markdown で記述されており、それ自体が何かを実行することはないため、開いて読むのは安全です。ただし、編集する場合は注意が必要です。エージェントは変更された内容に従って動作します。

記載する内容

必須の形式はありません。最も役に立つのは、エージェントがコードを読んだだけでは判断できない情報です：

  • コマンド： ビルドやテストの方法（自身の作業を確認するため）
  • プロジェクトのルール： 例えば、ユーザー向けのテキストを配置する場所など
  • 警告： 触れてはいけないフォルダや、繰り返し間違えてしまう点など

小さなファイルの例：

# CLAUDE.md

## Commands
- Test: npm test (run this before you finish)

## Rules
- Don't edit files in /generated
- Keep user-facing text in src/i18n

Anthropicのメモリに関するドキュメントでは、200行以内に収めることが推奨されています。長すぎるとエージェントの注意を消費し、指示が正しく守られにくくなるためです。

配置場所

ファイル 用途
プロジェクトのトップフォルダにある CLAUDE.md プロジェクト用の指示。通常は git で共有されます
サブフォルダにある CLAUDE.md エージェントがそのフォルダで作業する際に読み込まれる指示
~/.claude/CLAUDE.md すべてのプロジェクトで共通の個人的な設定
CLAUDE.local.md プロジェクトごとの個人的なメモ。git には含めないでください

Claude Code を起動した位置より上位のフォルダにあるファイルも読み込まれます。これらは置き換えではなく結合されるため、矛盾があるとエージェントが混乱する原因になります。

作成方法

Claude Code で /init を実行します。プロジェクト内をスキャンし、見つかったビルドコマンドや規約に基づいてファイルを下書きします。その後、自動検出されなかった内容を追加します。

最初から用意する必要はありません。同じミスを2回修正した時が作り時です。1行追加すれば、次のセッションではもうその指示が反映されます。

できないこと

Claude Code はこのファイルを絶対的なルールではなく「指針」として扱うため、通常は指示に従いますが、強制ではありません。絶対に避けなければならない事柄がある場合は、Anthropic はツールが毎回強制するフックの使用を推奨しています。行に「IMPORTANT（重要）」と追加しても、問題が解決することはほとんどありません。

パスワードや API キーは記述しないでください。プロジェクトファイルは通常コードと一緒にコミットされるため、プロジェクトを閲覧できる人なら誰でも読めてしまいます。

CLAUDE.md と AGENTS.md

AGENTS.md は Codex などの他のツールに対して同様の役割を果たします。また、Claude Code もプロジェクト内に既存のファイルがあればそれを読み込むことができます。コーディングエージェントが作成する他のファイルについては、コーディングエージェントが作成する .md ファイルに関するガイドをご覧ください。

スマホで読む方法

プレーンテキストアプリで開くと、# や ** の記号がそのまま表示されてしまいます。Android で綺麗に整形して読む手順は以下の通りです：

  1. ファイルをスマホに送信します。Claude Code は通常パソコン上で動作するため、Google Drive、メールの添付ファイル、または USB ケーブルを使用してください。
  2. ファイルをタップして MD Reader を選ぶか、アプリ内のファイルを開くを使用します。

Google Playで手に入れよう

見出し、テーブル、コードブロックが整形されて表示され、目次を使ってセクション間をジャンプできます。指示ファイルによく見られる <example> のようなタグは、消えてしまわずにそのまま表示されます。Google Drive の利用方法については、Google Drive から .md ファイルを開く方法をご覧ください。

MD Reader は Claude Code と接続したり、パソコンと同期したりすることはないため、閲覧しているのはコピーです。ファイルが変更されたら、再度送信してください。編集をタップしてコピーを変更することはできますが、ファイルをパソコンに戻すまで Claude Code にはその変更は反映されません。
