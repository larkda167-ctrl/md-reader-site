Claude Code や Codex が作成する .md ファイルとは？

更新日: 2026-11-03

Claude Code や Codex などの AI コーディングエージェントを使用していると、プロジェクトフォルダに .md で終わるファイルが増えてきます。メモ帳などで開くと、# や ** だらけで読みにくいと感じるかもしれません。しかし、これは故障ではなく、AI アシスタントが回答に使用しているのと同じ Markdown 文書です。人間と AI の双方が読めるプレーンテキスト形式であるため、エージェントによく利用されています。

よく見かけるファイル

ファイル名 内容
README.md プロジェクトの概要と実行方法
CLAUDE.md Claude Code がそのプロジェクトで読み込む常駐の指示書
AGENTS.md Codex などのエージェント向け常駐の指示書
PLAN.md、TODO.md、NOTES.md エージェントやユーザーが作成した計画、タスクリスト、メモ
CHANGELOG.md 各バージョンの変更履歴

最初の 3 つ以外はプロジェクトによって異なる場合があるため、用途が不明な場合は中身を確認してください。

CLAUDE.md と AGENTS.md の取り扱いには注意が必要です。 これらの内容を変更すると、そのプロジェクトにおけるエージェントの動作が変わります。読むだけであれば常に安全です。

これらのファイルを読むメリット

これらのファイルには、エージェントが何を計画し、何を実行し、何が残っているのかが記述されています。これらを飛ばしてしまうと、チャット上の要約だけに頼ることになってしまいます。また、内容が長いため、デスクから離れてスマートフォンで読む方が快適です。

スマートフォンで読む方法

これらのツールは通常コンピュータ上で動作するため、まずはファイルをスマートフォンに送る必要があります。

  1. ファイルを転送します。Google Drive、メールの添付ファイル、USB ケーブルなどが利用できます。
  2. スマートフォンで MD Reader を使って開きます。ファイルをタップして MD Reader を選択するか、アプリ内のファイルを開くを使用します。

Google Playで手に入れよう

見出し、テーブル、シンタックスハイライト付きのコードブロック、数式、Mermaid ダイアグラムが整形されて表示されます。フロントマターはカードとして表示され、指示書によく見られる <example> などのタグは消えずにそのまま表示されます。

MD Reader はコンピュータと同期せず、Claude Code や Codex に直接接続することもありません。開いているのはスマートフォンに送信したコピーです。エージェントがファイルを更新した場合は、再度ファイルを送信してください。詳しい手順については、Google Drive から .md ファイルを開く方法をご覧ください。

フォルダ全体を確認する

エージェントが 1 つのファイルだけで作業を終えることはまれです。フォルダワークスペース（Pro 版で近日公開予定）を使用すると、フォルダをスマートフォンにコピーして開き、すべての文書を横断して検索したり、文書間のリンクをたどったりできるようになります。

スマートフォンから計画を変更する

読書中にタスクリストのチェックボックスをタップすると、その場でファイルに保存されます。文言を変更するには、編集をタップして、記号を覚える必要なく、整形されたページ上で直接入力できます（編集の詳細についてはこちら）。読み取り専用のファイルの場合、MD Reader はコピーの保存先を確認します。変更内容をプロジェクトに反映させるには、ファイルをコンピュータに戻してください。
