ChatGPT の回答をスマホで綺麗に読む方法

更新日: 2026-11-03

ChatGPT は Markdown 形式で回答を作成します。ChatGPT アプリ内では綺麗に装飾されて表示されますが、メモアプリ、メッセージ、文書などにコピーすると、#、**、| などの記号だらけになってしまったり、構造が崩れたりすることがよくあります。

Markdown ビューアーを使えば、この問題が解決します。テキストを貼り付けるだけで、再び綺麗に装飾されます。

書式が消えてしまう理由

ほとんどの AI アプリのコピーボタンは、装飾された画面ではなく Markdown の原文をコピーします。Markdown を理解しないアプリでは、原文がそのままプレーンテキストとして表示されてしまいます。そのため、以下のような現象が起きます。

  • 見連が ## で始まる行になる
  • 太字が ** で囲まれる
  • 表が | --- | の行になる数式が $...$ や \frac{}{} のまま表示される

3ステップで綺麗に読む

  1. ChatGPT で回答の下にあるコピーアイコンをタップします。
  2. MD Reader を開き、クリップボードから貼り付けをタップします。
  3. 見出しから自動生成された目次付きで、回答が整った文書として開きます。

Google Playで手に入れよう

また、ChatGPT 内でテキストを選択し、共有から MD Reader を選ぶこともできます。

チャット内ではなく、この方法で読むメリット

  • 長い回答が読みやすい。 目次機能を使ってセクション間を素早く移動でき、最後に読んでいた位置も記憶されます。
  • 表が画面にぴったり収まる。 幅の広い表は、押し潰されることなく横スクロールできます。スマホでの Markdown テーブルの読み方をご覧ください。
  • 数式や図を描画。 LaTeX の数式や Mermaid の図は、オフラインでも描画されます。Markdown での LaTeX 数式をご覧ください。
  • 保存して残せる。 回答を .md ファイルとして保存すれば、どの Markdown アプリでも読み続けられます。AI の回答を Markdown として保存する方法をご覧ください。
  • 編集も可能。 記号を直接触ることなく、見やすい画面のまま回答の修正や注釈の追加ができます。

ヒント：文書として出力してもらう

回答を保存する予定がある場合は、ChatGPT に「見出し付きの Markdown 文書として書いて」と頼んでみてください。構造がよりすっきりと整理され、目次がさらに使いやすくなります。

同様の手順で、Claudeや Gemini、その他 Markdown で回答するアシスタントでもご利用いただけます。
