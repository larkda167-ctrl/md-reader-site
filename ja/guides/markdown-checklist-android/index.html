AndroidでMarkdownのチェックリストを使う方法

更新日: 2026-11-07

Markdownには、ToDoリストを簡単に作成できる書き方があります。

- [x] 航空券を予約する
- [ ] パスポートを更新する
- [ ] 充電器を詰める

[ ] は未完了のタスク、[x] は完了したタスクを表します。このようなタスクリストは、READMEやプロジェクトのメモ、持ち物リスト、学習計画、AIアシスタントが作成した計画などでよく使われます。

しかしスマートフォンでは、多くのアプリで角括弧のままテキストとして表示されたり、チェックボックスが表示されてもタップして切り替えられなかったりします。

ファイルに即座に反映されるチェックボックス

MD Readerでは、閲覧画面のままでもチェックリストを操作できます。

  1. .md ファイルを開きます。
  2. チェックボックスをタップします。
  3. 操作はこれだけです。変更は元のファイルにすぐ保存され、ソース内の [ ] が [x] に更新されます。

Google Playで手に入れよう

編集画面に切り替える必要はなく、角括弧などのMarkdown記法を意識することもありません。

新しいタスクを追加する

  1. 編集 をタップします。
  2. タスクの末尾にカーソルを置き、Enterキーを押して次のタスクを追加します。
  3. 新しくチェックリストを始める場合は、空行で / と入力し、チェックリスト を選択します。
  4. 保存 をタップします。

詳しくは Markdown構文を覚えずに編集する方法 をご覧ください。

便利な活用例

  • 同期フォルダに保存した .md ファイルでの買い物リストや持ち物リスト
  • README内のプロジェクトToDoリスト
  • 学習計画や読書リスト
  • AIアシスタントに作成してもらった計画：ChatGPTやClaudeにステップごとの計画をMarkdownのチェックリスト形式で出力してもらい、MD Readerに貼り付けてファイルとして保存します。詳しくは AIの回答をMarkdownとして保存する方法 をご覧ください。

クラウド同期フォルダ内のチェックリスト

Google Driveなどのクラウドアプリにメモを保存している場合は、そのアプリの「アプリで開く」オプションからファイルを開いてください。変更内容がクラウドに同期されるかどうかは、ご利用のクラウドアプリの仕様に依存します。詳しくは Google Driveから.mdファイルを開く方法 をご覧ください。

ToDoアプリではなくMarkdownを使う理由

.md ファイルのチェックリストは単なるプレーンテキストです。あらゆるエディタ、あらゆる端末、Gitのようなバージョン管理ツールでもそのまま扱えます。特定のアプリやサービスが終了してもデータが消える心配がなく、1つの文書の中にメモやリンク、表などと一緒にタスクをまとめられます。
